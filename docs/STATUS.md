# 작업 상태

**0.24.0 릴리스를 준비하고 있습니다.** 변경 내용과 설치 방법은 [릴리스 노트](releases/0.24.0.md), 사용법은 [Live 가이드](../guide/live.md)를 확인하세요.

## 이번 버전에서 확인할 것

- Video에서 녹화 스트림을 미리 준비합니다. 녹화 중 줌과 JPEG/YUV 스냅샷을 사용할 수 있습니다.
- PIP는 합성 파일을, Multi는 카메라별 파일을 저장합니다. 지원 조합은 기기마다 다릅니다.
- WB 프리셋은 버튼 아래 목록에서 고릅니다. Photo의 손떨림 보정과 Video의 DNG는 비활성화합니다.

## 검증 범위

Galaxy S25+ · Android 16에서 확인한 조합과 오류 경로는 [VIDEO 검증 기록](validation/video-mode-ready-20261011.md)에 있습니다. 다른 제조사 기기, 전체 CTS, 장시간 녹화는 이번 검증에 포함하지 않았습니다.

Baseline 기반 회귀 비교는 유지합니다. 내부 점수 초안은 2026-10-08에 제거했으며 새 run의 점수 필드는 호환을 위해 null로 남습니다. [점수 초안 보관 문서](archive/SCORING-v1-draft.md)를 참고하세요.

## 다음 검증

1. 다른 제조사 기기에서 출력·PIP 조합을 확인합니다.
2. 비충전 상태에서 녹화 성능을 측정합니다.
3. 인코더 drop과 10분 녹화 drift 측정을 별도 시나리오로 검증합니다.

과거 버전의 변경 목록은 [릴리스 기록](releases/), 마일스톤·측정 수치·당시 제약은 [이전 작업 기록](archive/STATUS-before-0.24.0.md)에 보관했습니다.
