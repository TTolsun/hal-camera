## 앱이 하는 일

HALCamera는 Camera HAL 개발자가 카메라 동작을 관측하는 Android 앱입니다. Camera2·CameraX를 통해 카메라를 구동하고, 앱에서 받은 콜백과 실행 시각을 기록합니다.

- **Auto Check**는 정해진 검사 순서를 실행하고 건강 상태를 판정합니다.
- **벤치마크**는 측정값을 저장하고 기준 실행이나 이전 실행과 비교합니다.
- **LIVE**는 관측값을 표시하고 문제 발생 시점의 이벤트를 내보낼 수 있습니다.

앱이 관측한 콜백 간격은 HAL 내부 처리 시간이나 프리뷰 표시 간격과 같지 않습니다. HAL의 문제인지 판단하려면 앱 기록과 시스템 자료를 함께 확인해야 합니다.

## 문서의 근거를 확인하는 방법

아키텍처와 디버깅 문서의 끝에서 **문서 검토 상태**를 펼치면 기준 앱 버전과 검토 커밋을 볼 수 있습니다. `코드 확인`은 구현을 대조했다는 뜻이며, 실제 기기에서 검증했다는 뜻은 아닙니다.

설계 이유는 [설계 결정 기록](_inputs/decisions.md)에 남긴 내용만 사용합니다. 기록되지 않은 이유와 아직 정리하지 않은 동작은 `확인 필요`로 표시합니다.
