# Manual Capture Review

사용자의 리뷰·머지·릴리스 요청에 따라 Codex가 코드와 문서를 대조했습니다. 독립된 사람의 승인이나 추가 기기 검증을 의미하지 않습니다. 기준은 최신 main의 `b05c089`이며 수동 제어 변경을 통합한 소스를 검토했습니다.

## Findings and Fixes

1. 카메라 종료 후 큐에 남은 설정 작업이 기기 정보를 조회할 수 있었습니다. handler에서 active를 다시 확인하고 기기 정보 조회 실패를 안내하도록 수정했습니다.
2. 노출 최소값보다 프레임 주기가 짧아 수동 노출이 불가능해도 수동 WB가 남을 수 있었습니다. canExpose로 정규화 조건을 통일하고 JVM 회귀 검증을 추가했습니다.
3. 요청 복구 뒤에도 거절된 AF 변경의 trigger가 전송될 수 있었습니다. 설정 제출에 성공했을 때만 trigger를 전송합니다.
4. CameraX 전환 버튼을 제거한 뒤 문서 비교 표에 이전 조작법이 남아 있었습니다. 기존 상단 엔진 버튼을 안내하는 내용으로 수정했습니다.

## Scope

프리뷰·사진·녹화·녹화 중 사진의 수동 요청 적용 순서, AE/AF 잠금·플래시 충돌, 프레임 주기 제한, capability 확인, 자동 복귀, 요청 거부 복구, UI 숫자 입력과 중복 정보 표시를 대조했습니다. 수동 제어는 Live 경로에만 적용하며 Benchmark StreamSpec·ValidityFlags·RegressionRules는 변경하지 않습니다. Telemetry의 추가 값은 메타데이터이며 픽셀 저장 경계를 바꾸지 않습니다.

문서 최신성 검토는 `verify --changes`에서 시작했습니다. 구조·모듈 역할·런타임 흐름·격리 규칙과 기기 관찰 원고는 기존 의미를 유지하며, engine 원고·Manual 패널 구조·UI 지침·빠른 시작은 변경된 코드에 맞췄습니다. 기존 기기 관찰을 새로운 수동 촬영 성능 결과로 확대하지 않았습니다. 검토 기록의 reviewer는 실제 수행자인 Codex를 명시합니다.

릴리스 전 자동 검사와 실기기 결과는 [검증 기록](manual-capture-20261001.md) 및 [릴리스 노트](../releases/0.18.0.md)에 분리해서 기록합니다.
