# Callback 조작부·RAW 표시 기기 검증

**Galaxy S25+에서 RAW On/Off 표시와 가벼운 Callback 조작부를 확인했습니다.**

- 검증일: 2026-10-11 (KST).
- 기기: Samsung SM-S936N, Android 16, QTI SM8750.
- APK: 0.24.0, 코드 `908d8aee`. 동일 서명의 release APK로 기존 앱을 업데이트했습니다.
- 도구: 무선 ADB, Android CLI의 UI·접근성 정보 조회, 로컬 스크린샷.

| 조건 | 관찰 결과 |
| --- | --- |
| Camera2 PHOTO, RAW Off | Live에 P·Y·J만 표시됐습니다. 크기 조작부의 접근성 설명에도 RAW가 없었습니다. |
| RAW 4080×3060 적용 | Live에 `RAW 4080×3060`, 접근성 설명에 `RAW 4080x3060`이 추가됐으며 프리뷰 프레임이 계속 표시됐습니다. |
| RAW Off로 복귀 후 Service 0+1 PIP | 메인·보조 P·J와 메인 Y가 표시됐고 RAW Off 문구는 없었습니다. |
| PIP Callback | ID·Hold의 배경과 테두리가 없어졌습니다. 라벨보다 현재 값이 또렷하고 순환 표시와 터치 동작은 유지됐습니다. |
| Hold 0→1→3→5→10→0초 | 모든 값에서 ID 버튼 중심은 `[873,1454]`, Hold 버튼 중심은 `[1204,1454]`로 같았습니다. 시간 변경으로 두 버튼이 움직이지 않았습니다. |
| ID 0→1 전환 | 보조 장치의 독립 프레임과 YUV 없는 출력 행이 표시됐습니다. 행 수에 따른 세로 이동 후에도 ID·Hold의 가로 위치는 유지됐습니다. |

카메라 영상과 상태바 정보가 담긴 검증 이미지는 로컬에 보관했습니다. 검증한 범위는 기본 글꼴의 세로 화면이며 큰 글꼴·다른 기기와 밝은 영상 위 Callback 대비는 별도 검증이 필요합니다.

서명 release 빌드, JVM 테스트 784개, Android lint, 문서 회귀 테스트 33개와 문서 검사 7단계가 통과했습니다. 독립 모델 리뷰에서 수정할 회귀는 발견되지 않았습니다. 촬영·고정·연속 ID 전환의 이전 검증은 [FPS·Callback 기기 검증](live-fps-callback-2026-10-11.md)에서 확인하세요.
