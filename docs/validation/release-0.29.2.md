# 0.29.2 검증

**lint 정리와 녹화 코드 정리 뒤에도 Multi V의 카메라별 원본과 공유 마이크 오디오가 0.29.1과 같은 범위로 저장됩니다.** 2026-10-17 Galaxy S25+ (SM-S936N), Android 16에서 정식 서명 APK를 `adb install -r`로 설치했습니다. 앱 삭제나 데이터 초기화는 하지 않았습니다.

## 코드 검증

- `assembleRelease`, `testDebugUnitTest`, `lintDebug`가 통과했습니다. JVM 테스트는 840개이며 lint는 오류 0개·경고 0개입니다.
- 경고별 처리와 억제 근거는 [lint 검토 기록](lint-audit-20261017.md)의 2차 정리 절에 있습니다.
- 마이크와 영상 인코더가 각자 갖고 있던 출력 → MP4 기록 루프를 `EncoderTrack` 하나로 합쳤습니다. 실패 경로에서 시작된 muxer를 멈추는 순서도 그대로 유지합니다.
- 화면 회전 상수와 각도의 변환이 다섯 곳에 반복되어 있었습니다. 이를 `DisplayRotation`으로 합치고 JVM 테스트 2개를 추가했습니다.

## 기기 녹화 확인

후면 0번과 전면 1번 카메라를 Split으로 배치해 Multi V를 녹화했습니다. 오디오의 끝 시각에서 영상의 끝 시각을 뺀 값이 양수이면 오디오가 늦게 끝났다는 뜻입니다.

| 엔진 | 카메라 | 영상 길이 | 프레임 | 오디오 끝 시각 차이 |
| --- | --- | ---: | ---: | ---: |
| Camera2 | 후면 0 | 6.401초 | 191 (29.8fps) | +7.3ms |
| Camera2 | 전면 1 | 6.400초 | 192 (30.0fps) | +12.3ms |
| CameraX | 후면 0 | 5.589초 | 98 (17.5fps) | +16.8ms |
| CameraX | 전면 1 | 5.566초 | 167 (30.0fps) | +17.9ms |

- 네 파일 모두 H.264 720×1280 영상과 48kHz AAC 오디오를 포함하며, FFmpeg 전체 디코딩을 통과했습니다.
- 같은 녹화에 속한 두 파일의 오디오 peak는 같았습니다(Camera2 −25.0dB, CameraX −23.4dB). 하나의 마이크를 공유하는 설계와 일치합니다. 서로 다른 녹화끼리는 값이 달랐으므로 무음이나 복사된 오디오가 아닙니다.
- CameraX 후면의 17.5fps는 어두운 장면에서 AE가 노출을 41.6ms로 늘린 결과입니다. 녹화 전 프리뷰에도 FPS 15.0이 표시되었습니다. 같은 장면의 Camera2 후면은 노출 33.3ms에서 29.8fps였으므로, 두 엔진의 AE 프레임 속도 선택 차이로 보이며 이번 변경과 관계가 없습니다.

## 검증하지 않은 범위

박수를 이용한 영상·소리 동기 측정은 반복하지 않았습니다. 시각 계산 코드가 바뀌지 않았으므로 [0.29.1 검증 기록](release-0.29.1.md)의 30~80ms 잔여 오차를 그대로 적용합니다. 테마 아이콘은 빌드 결과만 확인했고 런처 화면에서는 확인하지 않았습니다. 대화면 회전, 번역, 다른 기기는 검증하지 않았습니다. 검증용 영상 4개는 기기의 DCIM/HALCamera에 남겼습니다.
