# Multi Split 재검증

최신 main `17f3beb5`에 Multi Split을 rebase하고 같은 release 서명의 0.25.0 APK를 기존 앱 위에 설치했습니다. 기존 앱과 데이터를 삭제하지 않았습니다. Galaxy S25+ (`SM-S936N`, Android 16)에서 아래 버튼을 실제로 조작해 검증했습니다.

| 조작 | 결과 |
| --- | --- |
| Split·닫기·Apply | 위에서 내려오는 설정창, 취소 시 설정 유지, 배치만 변경할 때 세션 유지가 통과했습니다. |
| 카메라 아이콘·조합·화면별 선택 | 0+1과 0+3 조합, 화면별 카메라 순서 변경과 복원이 통과했습니다. |
| 위아래·좌우 배치 | 각 프리뷰가 전체 입력을 유지했습니다. 두 카메라에서 중복되는 Grid 선택은 숨겼습니다. 3개 이상 격자는 JVM 배치 검사만 수행했습니다. |
| 카메라 수 | 광고된 조합의 수만 표시합니다. 이 기기는 2개로 고정되어 선택창을 비활성화했습니다. |
| 상단 제어 | Manual 제외, AEB 비활성, AF·AE 잠금과 해제, EV 증가·초기화, Torch·Off가 통과했습니다. AE·EV·줌은 HAL 결과를 대조했습니다. |
| 줌·프리뷰 터치 | 줌 선택·복원, 터치 초점 요청과 핀치 줌 적용이 통과했습니다. |
| Callback·ID·Hold | 표시·숨기기, 카메라 ID 전환, Hold 변경이 통과했습니다. GPU 인코더를 HAL 녹화 출력으로 표시하지 않습니다. |
| 사진 셔터·Details | 카메라 0·1에서 각각 1920×1440 원본 JPEG를 저장했습니다. 각 이미지와 결과의 센서 시각이 일치했고 묶음 JSON은 `camera JPEG`를 기록했습니다. |
| 녹화 셔터·정지 | 카메라별 720×1280 MP4 두 개가 각각 재생됐습니다. 2초 이상의 지속 시간, 무음과 장치별 크기를 확인했습니다. |
| 녹화 중 사진 | 장치별 원본 사진을 저장하는 동안 두 영상의 녹화가 유지됐습니다. |
| Gallery·Lab·뒤로 가기 | 진입 후 Multi 프리뷰를 복원했습니다. 복귀 시 뷰 크기가 확정된 뒤 다시 시작하도록 수정했습니다. |
| Save Events·Share | ZIP 저장과 공유 대상 선택창 진입이 통과했습니다. 대상에게 전송하지 않고 닫았습니다. |
| Retry | 테스트에서 주입한 실패 뒤 기존 카메라를 닫고 두 프리뷰를 다시 열었습니다. 실제 기기 오류를 유발한 검사는 아닙니다. |
| Photo·Video·Multi P·Multi V | 모드 이동과 카메라 해제 후 Live 복원이 통과했습니다. |

화면과 저장 영상의 디코딩 프레임도 로컬에서 확인했습니다. 카메라 영상과 UI는 다른 장치의 저장 파일에 합성되지 않았습니다. 촬영 자료는 검증용 로컬 파일로 유지하며 이 문서에 포함하지 않습니다.

`assembleRelease`, app JVM 테스트 810개, `lintDebug`, 문서 회귀 검사 33개와 문서 검사 6단계가 통과했습니다. 기기 검사는 `MultiSplitChecks`를 `multi_split=true`로 실행했습니다. Camera2·무음 녹화와 Off·Torch 제한은 유지합니다.

초기 검증의 연결 중단 항목은 이번 검사로 확인했습니다. 초기 기록은 [2026-10-11 기록](multi-split-20261011.md)에 있습니다.
