# 벤치마크 녹화 진행 표시 검증

Recording 단계에서 화면의 프레임 수가 멈추던 문제를 수정했습니다. 기존 화면은 YUV `image_available`만 집계했지만 녹화 세션은 프리뷰와 녹화기 출력만 사용했습니다. 실제 녹화는 진행되더라도 화면에는 이전 프레임 수가 남았습니다.

## 변경 내용

- 현재 세션과 녹화 회차의 `record-N` 태그가 일치하는 `capture_result`로 화면용 통계를 집계합니다. 준비용 태그와 다른 회차의 늦은 콜백은 제외합니다.
- 녹화 통계는 회차별로 초기화합니다. 프리뷰 통계와 세션 재구성 시간을 섞지 않으며, 화면에 `Recording frames (this cycle)`을 표시합니다.
- Runner의 진행 콜백이 녹화 단계에서는 녹화 회차와 총 횟수를 전달합니다. 측정 시퀀스와 실행 제한은 바꾸지 않았습니다.
- 현재 회차, 준비·시작·녹화·저장 상태, 녹화 경과 시간을 표시합니다. 기존 화면 갱신 타이머에서 회차 내 진행률을 계산합니다. 진행률은 시간에 따른 표시용 추정치이며 실제 프레임 수는 콜백이 있어야 증가합니다.
- 저장 보고서의 측정·validity·점수 계산에는 화면용 통계를 사용하지 않습니다.

## 자동 검사

`testDebugUnitTest`, `lintDebug`, `assembleRelease`를 통과했습니다. 추가 테스트는 회차 표시, 회차 내 진행률과 경계, 준비·녹화·저장 문구를 확인합니다. Runner의 기존 녹화 시퀀스 테스트에는 다섯 회차의 진행 콜백이 0부터 4까지 실제 녹화 인덱스와 총 횟수 5를 전달하는 검사를 추가했고 해당 테스트도 통과했습니다.

## 실기기 결과

Galaxy S25+ (`SM-S936N`)·Android 16에 동일한 릴리스 서명의 0.19.0 APK를 `adb install -r`로 업데이트했습니다. 데이터 초기화는 하지 않았습니다. `benchmark run --camera 0 --no-wait`로 실행한 요청은 `005efffd-a329-41f1-891b-c0a45a0cd3f1`입니다.

| 화면 | 관찰 결과 |
| --- | --- |
| [녹화 2/5](assets/benchmark-recording-progress-20261006/recording-b.png) | 경과 시간 5.3/9.0초, 진행률 56%, 프레임 151, interval p50 33.3ms를 표시했습니다. |
| [녹화 4/5](assets/benchmark-recording-progress-20261006/recording-c.png) | 경과 시간 2.6/9.0초, 진행률 77%, 현재 회차 프레임 71, interval p50 33.3ms를 표시했습니다. |
| [완료 화면](assets/benchmark-recording-progress-20261006/recording-d.png) | 정상적으로 결과 화면으로 전환됐습니다. |

회차별 프레임 수이므로 새 회차에서 숫자가 작아지는 것은 정상입니다. 두 녹화 화면 모두 텍스트가 잘리지 않고 카드 안에 표시되는 것을 확인했습니다. 화면 캡처와 결과 읽기에는 `android-cli` 스킬의 화면 검사 절차와 adb CLI를 사용했습니다.

run `20261006-085901-722`의 다섯 녹화 회차가 모두 실패 없이 완료됐습니다. 저장 보고서의 프레임 수는 순서대로 267·269·269·269·261이며 FPS 중앙값은 모두 30입니다. CLI 요청은 succeeded, 보고서는 schema 5로 저장됐습니다. [요청 결과](assets/benchmark-recording-progress-20261006/request.json)의 파일 해시와 PC로 회수한 JSON의 SHA-256은 `eb836440d57e7dbeecdfcf424998ed7f5e4acab19e0b561e2a906467ca879e77`로 일치했습니다.

APK와 원본 보고서는 작업 폴더의 `releases/cli-benchmark-validation/`에 보관했습니다. 이 검증은 후면 카메라 0의 정상 완료 한 번을 대상으로 하며 다른 기기·큰 글꼴 설정은 추가 확인이 필요합니다. 이전 CLI 작업에서 남은 구조 문서의 최신성 재검토 상태는 별도로 유지합니다.

관련 사용법은 [CLI 가이드](../../guide/cli.md)를 확인하세요.
