## SOLID와 유지보수성 판단

선택 규칙과 배치 계산은 Android 의존성이 없는 `SplitSelection`·`SplitArrangement`에 남고, 화면은 이를 조합합니다. 공통 선택 버튼은 콜백으로 변경을 전달하며 카메라 엔진이나 세션을 직접 알지 않습니다. 사용하지 않는 인터페이스를 추가하지 않았습니다. 엔진 대체 계약과 close(done) 순서는 변경하지 않았습니다.

문서는 Live의 사용자 절차, `.omm`의 구조 근거, 릴리스별 검증 기록으로 책임을 나눕니다. 생성된 guide 블록과 HTML은 생성기로만 갱신합니다. 과거 릴리스 기록과 당시 기기 검증값은 현재 동작으로 덮어쓰지 않습니다. 문서에 SOLID를 기계적으로 적용하기보다 책임·원본·참조 경계가 명확한지 검사했습니다.

## 검증

- `assembleRelease assembleDebug testDebugUnitTest lintDebug`가 통과했습니다. app JVM 테스트는 826개이며 실패가 없습니다. lint는 오류 0개, 기존 경고 159개이며 미사용 리소스 경고는 없어졌습니다.
- 문서 check --build 6단계와 회귀·내부 링크 검사 33개가 통과했습니다. 생성된 버전 정보는 0.27.0(681)로 갱신했으며, 과거 기기 기록의 버전은 유지했습니다.
- SM-S936N(Galaxy S25+) · Android 16에 정식 APK를 `install -r`로 업데이트했습니다. 기존 versionCode 680에서 681로 올라갔으며 앱 삭제나 데이터 초기화는 하지 않았습니다.
- Sizes에서 Rear Preview 640×480을 선택하면 버튼과 접근성 설명이 함께 바뀌었습니다. 닫으면 기존 1280×720을 유지하고, 다시 골라 Apply하면 Rear만 640×480으로 바뀌었습니다.
- ID 드래그로 Front/Rear 순서를 바꾼 뒤 P→V→P에서 순서·크기와 카메라별 FPS/EXP가 유지되었습니다. 정식 APK에서 짧은 녹화를 끝내 `Videos saved · Details`, 사진 촬영 후 `Photos saved · Details`를 확인했습니다. 파일 픽셀·코덱 재분석은 하지 않았습니다.
- 패키지 dev.halcamera, versionName 0.27.0, versionCode 681, minSdk 26, targetSdk 36과 비디버그 설정을 확인했습니다. APK 서명 검증을 통과했으며 인증서 SHA-256은 기존 정식 인증서인 `f2432413635645cc35e674e498e88ff518abb878065c21f17bb3c2128487b5c1`과 일치합니다.

세 카메라 이상·다른 제조사·장시간 녹화는 실측하지 않았습니다. 이전 UI 화면과 검증은 [Multi UI 검증 기록](multi-photo-ui-20261017.md)을 참고하세요. 검토자는 사용자 요청에 따른 Codex이며 별도 사람의 리뷰를 뜻하지 않습니다.
