# 0.28.0 릴리스 검증

0.27.0 이후 PR #292의 전체 코드·문서 정리, #293의 다운로드 페이지, #294의 lint 검토를 포함합니다. 기준 코드는 `7666395e`이며 릴리스 버전은 0.28.0(682)입니다.

## 빌드와 코드 검증

- 정식 서명으로 `assembleRelease`, `testDebugUnitTest`, `lintDebug`가 통과했습니다. JVM 테스트 828개는 실패가 없으며 lint는 오류 0개·경고 132개입니다.
- 문서 회귀 검사 33개와 문서 파이프라인 6단계가 통과했습니다. 생성된 버전 표와 배포 사이트를 함께 갱신했습니다.
- APK 패키지 `dev.halcamera`, minSdk 26, targetSdk 36과 비디버그 설정을 확인했습니다. 인증서 SHA-256은 기존 정식 인증서 `f2432413635645cc35e674e498e88ff518abb878065c21f17bb3c2128487b5c1`과 같습니다.
- 배포 APK의 SHA-256은 `2cec3efbab38869f68b812120c12746c6d1d46dc93d9791e34ab4ce4e7ca8d80`입니다. 배포 스킬은 이 릴리스의 `skills/halcam-cli/SKILL.md`와 동일하며 두 첨부물의 해시를 SHA256SUMS.txt에 제공합니다.
- 서명 설정과 키는 원래 위치에서 참조했으며 별도 복사본을 만들지 않았습니다. 저장소와 릴리스 첨부물에 자격 증명을 넣지 않습니다.
- 전체 정리 범위는 [저장소 검토](repository-audit-20261017.md), lint 159개 판정과 Android 16 기기 회귀 검사는 [lint 검토](lint-audit-20261017.md)에 있습니다.

## 데이터 보존 업데이트

SM-S936N(Galaxy S25+) · Android 16에서 기존 0.27.0(681)을 `adb install -r`로 0.28.0(682)으로 업데이트했습니다. 정식 앱을 삭제하거나 데이터를 초기화하지 않았습니다. 기존 실행 목록 31개와 실행 보관 한도 Unlimited(0)를 설치 전후로 대조해 일치함을 확인했습니다. 최초 설치 시각도 유지됐습니다.

별도 검증 앱 `dev.halcamera.uiverify`, `dev.halcamera.lintverify`의 내부 데이터와 디버그 테스트 패키지 데이터는 PC에 tar로 보관했습니다. 정식 앱의 데이터 보존과 검증용 패키지 제거를 구분합니다. 비디버그 테스트 패키지 `dev.halcamera.test`는 run-as 백업이 지원되지 않으며 제품 사용자 데이터의 저장소가 아닙니다. 사용자 요청에 따라 검증 앱 두 개와 테스트 패키지 두 개를 제거했고 기본 사용자의 HAL CAM 패키지는 dev.halcamera만 남았습니다. 정리 전후 MediaStore 목록 293개(ID·이름·크기)가 동일했습니다. 정식 앱의 Live 화면을 열어 프레임·노출 정보 갱신과 기존 갤러리 썸네일을 확인했습니다.

## 한계

기존 기기 회귀 검사는 SM-S936N Android 16에서 EXIF 방향값 1–8, 갤러리·셔터 클릭과 접근성 클릭, Split 핸들 탭, 반복 그리기와 Live EV 화면을 확인했습니다. Android 8·8.1 실기기, 실제 OS 복원, TalkBack 전체 흐름과 대화면 회전은 검증하지 않았습니다. 이 릴리스 검토의 주체는 사용자 요청에 따른 Codex이며 별도 사람 리뷰를 의미하지 않습니다.

설치 파일은 [0.28.0 릴리스](https://github.com/TTolsun/hal-camera/releases/tag/v0.28.0)에서 받습니다.
