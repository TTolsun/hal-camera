# 0.29.1 Multi 영상·오디오 검증

**종료 시 오디오가 먼저 끊기던 차이는 줄었으며, 실제 박수 동기에는 수십 ms의 잔여 오차가 있습니다.** 2026-10-17 Galaxy S25+ (SM-S936N), Android 16에서 Camera2와 CameraX Multi V의 전·후면 원본을 확인했습니다. 앱 삭제나 데이터 초기화 없이 정식 서명 APK를 `adb install -r`로 설치했습니다.

## 코드 검증

- `assembleRelease`, `testDebugUnitTest`, `lintDebug`가 통과했습니다. JVM 테스트는 838개이며 lint 오류 0개·경고 131개입니다.
- 하드웨어 PCM 시각의 원점 계산, 긴 프레임 카운트의 overflow 방지, 인코더가 시작 프레임을 버렸을 때의 영상 원점, 중복·역행 timestamp 거부를 회귀 테스트로 검증했습니다.
- 플랫폼 녹음·인코딩과 순수 Kotlin 시각 계산을 분리했습니다. 기존 PIP의 MediaRecorder와 Multi의 timestamp 보존 인코더는 `SurfaceRecording` 계약을 공유합니다. 사용하지 않는 요청 시작 시각과 임시 진단 로그를 제거했습니다.

## 실제 박수와 파일 조사

사용자가 전면 카메라 앞에서 박수를 세 번 쳤습니다. PC에서 FFprobe의 원래 프레임 PTS와 48kHz로 디코딩한 오디오의 1ms RMS 피크를 비교했습니다. 아래 값은 트랙의 길이만 비교한 값이 아니라 `start_time + duration`으로 계산한 끝 시각입니다. 양수는 오디오가 영상보다 늦게 끝났다는 뜻입니다.

| 녹화 경로 | 영상 끝 | 오디오 끝 | 끝 시각 차이 |
| --- | ---: | ---: | ---: |
| 0.29.0 Camera2 전면 비교본 | 30.490711초 | 30.237646초 | -253.1ms |
| 0.29.1 Camera2 전면 | 65.929100초 | 65.937396초 | +8.3ms |
| 0.29.1 Camera2 후면 | 65.982667초 | 66.003292초 | +20.6ms |
| 0.29.1 CameraX 전면 | 31.431322초 | 31.442500초 | +11.2ms |
| 0.29.1 CameraX 후면 | 31.431989초 | 31.436708초 | +4.7ms |

Camera2 전면의 소리 피크는 41.691·42.218·42.766초였고 손 접촉은 각각 약 41.63~41.66·42.13~42.16·42.70~42.73초의 프레임에서 관찰했습니다. CameraX의 피크는 19.953·20.407·20.850초였으며 접촉 프레임은 약 19.90·20.33~20.37·20.80초였습니다. 전체적으로 소리가 접촉보다 대략 30~80ms 뒤따랐습니다. 30fps 영상과 손의 모션 블러를 사용한 수동 판독이므로 이 수치를 샘플 단위 정밀 측정으로 해석하면 안 됩니다.

0.29.0 비교본의 첫 박수는 소리가 14.046초, 손 접촉은 14.159~14.231초 사이여서 소리가 약 110~190ms 먼저 나왔습니다. 수정 과정에서 마이크 하드웨어 시각만 도입한 중간 빌드도 별도로 시험했으나, 최종 수치는 실제 인코딩된 영상 프레임의 시각까지 보존한 빌드의 결과입니다. 진단 로그 제거와 종료 처리 정리 뒤 최종 APK의 저장 동작도 다시 확인합니다.

네 파일은 각각 H.264 영상과 같은 마이크의 48kHz AAC를 포함합니다. 전면 영상은 약 30fps, 후면은 Camera2 약 29.8fps·CameraX 약 29.0fps였습니다. 원본의 전체 디코딩으로 파일 손상 여부를 검사했습니다. 개인 영상과 오디오 원본은 공개 저장소에 올리지 않았습니다.

## 남은 제약

AAC는 48kHz에서 1024샘플, 약 21.3ms 단위이므로 마지막 패킷의 끝은 영상 끝과 정확히 일치하지 않을 수 있습니다. 잔여 박수 오차에 센서·마이크 처리, AAC 지연, 프레임 판독 오차가 각각 얼마나 기여했는지는 분리하지 않았으며 기기 제약으로 단정하지 않습니다.

센서 시계 출처가 REALTIME이 아니면 영상 프레임의 도착 시각을 사용합니다. 마이크의 하드웨어 시각을 얻지 못하면 오류로 종료합니다. 다른 기기, 외부 마이크, 블루투스, 10분 이상 녹화의 drift, 저장 공간 부족 등의 하드웨어 실패 주입은 검증하지 않았습니다. 전·후면 센서의 노출 시점을 동기화하는 기능은 아닙니다.
