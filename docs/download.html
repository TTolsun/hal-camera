HAL CAMERA / User Guide

Download. Install. Explore.

HALCamera APK는 GitHub Releases에서 받을 수 있습니다. 최신 릴리스를 열어 변경 사항을 확인하고, Assets에서 .apk 파일을 내려받으세요.

최신 릴리스 열기최신 버전의 APK와 변경 사항을 확인합니다.↗ 전체 릴리스 보기이전 버전이나 지정된 검증 빌드를 찾습니다.↗

받을 파일을 고르세요

릴리스 페이지의 Assets를 펼쳐 필요한 파일을 선택하세요. 팀에서 지정한 검증 빌드가 있다면 해당 버전의 릴리스를 사용하세요.

파일 용도
HAL-Camera-*.apk Android 기기에 설치하는 앱입니다.
halcam-cli-*-SKILL.md 코딩 에이전트로 앱을 조작할 때 사용하는 스킬입니다. APK와 같은 릴리스의 파일을 받으세요.
SHA256SUMS.txt 내려받은 파일의 SHA-256 해시를 확인할 때 사용합니다.

GitHub의 Source code (zip)과 Source code (tar.gz)는 소스 코드 압축 파일입니다. 앱을 설치하려면 .apk 파일을 선택하세요.

설치하고 첫 촬영을 확인하세요

받은 APK의 설치 방법과 권한 설정은 Quickstart에 안내되어 있습니다. 업데이트할 때 서명 오류가 나면 기존 설치와 같은 서명의 APK를 받으세요. 앱을 삭제하면 내부 실행 기록이 사라집니다.

다음 단계: Quickstart에서 앱을 설치하고 첫 촬영을 확인하세요.
