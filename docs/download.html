HAL CAMERA / User Guide

Get HALCamera.

한 장을 찍고, 그 안의 시간을 살펴보세요.

HALCamera의 최신 설치 파일은 GitHub 릴리스에서 받을 수 있습니다.

최신 APK 받기Assets에서 APK 파일을 고릅니다.↗

이전 버전이 필요하면 전체 릴리스를 확인하세요.

설치하고 첫 촬영을 시작하세요

  1. GitHub 릴리스의 Assets에서 HAL-Camera-*.apk를 받습니다.
  2. Android 기기에서 파일을 열어 설치합니다.
  3. Quickstart를 따라 권한을 허용하고 첫 사진을 찍습니다.

업데이트에서 서명 오류가 나면 기존 설치와 같은 서명의 APK를 받으세요.

앱을 삭제하면 내부 실행 기록이 사라집니다.

릴리스에 함께 있는 파일은 무엇인가요?
  • halcam-cli-*-SKILL.md · 코딩 에이전트로 앱을 조작할 때 받습니다. APK와 같은 릴리스의 파일을 사용하세요.
  • halcamera_cli-*.whl · PC에 Python 클라이언트를 설치할 때 사용합니다. Python 3.11 이상이 필요합니다.
  • SHA256SUMS.txt · 내려받은 파일의 SHA-256 해시를 확인할 때 사용합니다.

앱 설치에는 .apk 파일만 있으면 됩니다.

기본 ADB 명령을 쓴다면 Python 클라이언트를 받지 않아도 됩니다.

Source code (zip)과 Source code (tar.gz)는 소스 코드입니다.

다음 단계: Quickstart에서 첫 사진을 찍어 보세요.
