# HAL CAM 0.31.0

Callback에서 Camera2와 CameraX Dual의 프레임별 출력을 확인할 수 있습니다.

- Camera2 Dual에서 사진을 찍으면 해당 프레임에 두 물리 카메라의 사진 행이 표시됩니다. Hold를 켜면 프리뷰가 재개된 뒤에도 지정한 시간 동안 사진 프레임을 볼 수 있습니다.
- CameraX Dual은 메인과 서브 Preview가 GL 입력 버퍼를 읽은 시각을 각각 기록합니다. 프레임의 물리 카메라 ID와 타임스탬프가 정확히 맞을 때만 해당 행에 시간값이 표시됩니다. 일치하는 입력이 없으면 행에 `Awaiting data`가 표시됩니다.
- CameraX Video에서 녹화 준비가 실패하면 이미 바인딩한 출력은 Callback에서 계속 확인할 수 있습니다.
- 개발 버전에 포함됐던 Depth/Bokeh 기능과 관련 모델을 제거했습니다.

정식 APK는 `HAL-Camera-0.31.0.apk`이며 패키지는 `dev.halcamera`, versionCode는 `692`입니다. 기존 정식 앱에 업데이트로 설치하면 앱 데이터를 유지할 수 있습니다. 함께 제공하는 PC용 CLI는 0.5.0입니다.

기기별 관측 결과는 [Galaxy S25+ 검증 기록](https://github.com/TTolsun/hal-camera/blob/v0.31.0/docs/validation/callback-frame-outputs.md)에서 확인할 수 있습니다.
