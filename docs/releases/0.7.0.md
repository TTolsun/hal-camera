# HAL CAM 0.7.0

같은 기기의 소프트웨어 수정 전후를 반복 측정 묶음으로 비교하고, 외부 프로파일링 JSON도 불러올 수 있습니다. 새 PROBE 화면은 카메라를 열지 않고 Camera2 HAL이 공개한 사양을 카메라별로 보여 줍니다.

## 설치

첨부된 `HAL-Camera-0.7.0.apk`를 설치하세요. 기존 정식 앱과 같은 인증서로 서명했으므로 기존 앱 위에 업데이트할 수 있습니다. 실행 기록과 baseline을 유지합니다.

| 항목 | 값 |
| --- | --- |
| 패키지 | `dev.halcamera` |
| 버전 | `0.7.0` · versionCode `10` |
| 지원 Android | Android 8.0 이상 · minSdk 26 / targetSdk 36 |
| 빌드 | 서명된 Release · debuggable=false |
| 인증서 SHA-256 | `f2432413635645cc35e674e498e88ff518abb878065c21f17bb3c2128487b5c1` |

파일 해시는 첨부된 `SHA256SUMS.txt`에서 확인합니다. PC CLI는 변경 없이 0.1.0을 사용하며 [0.6.0 릴리스의 wheel](https://github.com/TTolsun/hal-camera/releases/tag/v0.6.0)을 설치할 수 있습니다.

## 변경 사항

- RESULTS의 **반복 측정 비교 · JSON 가져오기**에서 수정 전과 수정 후의 실행 묶음을 선택합니다. 실행 수, 평균, 중앙값, 표준편차, 차이와 변화율을 표시합니다.
- 실행 단위의 양측 순열검정과 Bonferroni 보정을 제공합니다. 통계적 유의성과 기존 실무 임계값 판정을 구분하며, 표본 부족과 비교 제한·제외 사유를 표시합니다.
- 시스템 파일 선택기로 schema 3·4 JSON을 가져오고 기기별로 선택·열람·비교합니다. 원본은 SHA-256으로 식별해 별도로 저장하며 기존 로컬 baseline과 reference를 변경하지 않습니다.
- 중복 실행과 기기·빌드·카메라·계약·환경 조건을 확인합니다. 선택 복원, 최근 결과 다시 열기, 결과 텍스트 공유와 가져온 사본 삭제를 지원합니다.
- 개발자 문서의 선택적 동기화와 입력 크기·시간 제한 처리를 개선하고, 기존 S25+ 측정 결과의 회귀 검사를 보강했습니다.
- **PROBE · 카메라 사양**(LIVE 진단 패널과 BENCHMARK 시작 카드에서 진입)은 공개 카메라 ID 전부와 논리 카메라 뒤의 물리 카메라까지 `CameraCharacteristics`를 읽어 IDENTITY, CAPABILITIES, SENSOR, LENS, CONTROL, PROCESSING, REQUEST, 포맷별 STREAMS(종횡비·최소 프레임 간격·stall), mandatory stream combination, 모든 키 원본 덤프를 섹션으로 보여 줍니다. enum은 플랫폼이 정의한 값 전체를 ✓/✗로 나열합니다.
- PROBE 하단 필터에 단어를 넣으면 그 단어가 든 줄만 섹션·키별로 묶어 보여 주고, 항목을 누르면 해당 줄로 이동해 강조합니다. TXT/JSON 공유와 클립보드 복사를 제공하며 이미지 픽셀은 저장하지 않습니다.

## 검증과 해석 범위

0.7.0 버전에서 Debug·Release 단위 테스트를 각각 318개 통과했고, 두 빌드와 lint를 확인했습니다. APK의 버전·패키지와 기존 정식 인증서 일치를 검사했습니다.

기능 PR #72에서 S25+ SM-S936N / Android 16의 Android JSON·파일 경계 검사 24개와 실제 파일 선택·가져오기·필터·전후 선택·분석·복원·공유 선택기·사본 삭제 흐름을 검증했습니다. 이 UI 검증에는 명시적인 합성 자료를 사용했습니다. 이번 버전 번호 변경 후 새 카메라 측정은 수행하지 않았습니다.

PROBE는 PR #75에서 같은 S25+의 카메라 6개(공개 0·1·2·3, 물리 5·6) 열람, 섹션 접기·펼치기, TXT 공유, 필터와 항목 이동을 확인했고, Camera2 API Probe 앱과 대조해 하드웨어 레벨·물리 ID·JPEG 크기와 종횡비·화면 정보가 일치함을 확인했습니다. PROBE가 보여 주는 값은 HAL이 공개한 사양이며 측정 결과가 아닙니다.

지표별 각 5회 이상, 묶음별 최대 50회를 지원합니다. 최소 5회는 충분한 검정력을 보장하지 않으며 유의차 미검출은 동등성의 증명이 아닙니다. 다른 기기 간 비교는 탐색 용도이며 동일 기기의 SW 수정 효과로 해석할 수 없습니다. 실제 Exynos 수정 효과는 해당 기기에서 수집한 자료로 판단해야 합니다.
