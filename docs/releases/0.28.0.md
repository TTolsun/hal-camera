# HAL CAM 0.28.0

**전체 코드·문서 검토와 lint 정리를 반영한 유지보수 릴리스입니다.** 0.27.0의 Multi 조작과 카메라별 크기·FPS/EXP, P/V 전환 시 스트림 재구성은 유지합니다.

## 달라진 점

- PC 집계 도구가 현재 schema 5 결과와 녹화 누락 플래그를 앱과 같은 규칙으로 처리합니다. CSV·유효성·읽기 버전 계약의 차이를 CI에서 검사합니다.
- 미사용 코드와 CTS 화면의 중복 구성을 정리하고, 현재 동작과 어긋난 문서 설명을 갱신했습니다.
- EXIF를 AndroidX로 전환하고 Live 제어판·결과 막대의 그리기 중 Path 할당을 줄였습니다. 기존 백업 제외 정책을 Android 12 이상 기기 이전 규칙에도 명시했습니다.
- lint 159개를 모두 검토했습니다. 실제 수정 9개와 오탐 한정 억제 18개를 반영해 오류 0개·경고 132개가 남았습니다. 나머지 경고의 근거는 검토 기록에 보관합니다.
- 홈페이지에 GitHub Releases로 연결되는 다운로드 페이지를 추가했습니다.

## 업데이트

`HAL-Camera-0.28.0.apk`를 기존 앱 위에 설치하세요. 패키지는 `dev.halcamera`, versionCode는 `682`이며 기존 정식 서명을 사용합니다. 앱을 삭제하지 않아야 내부 실행 기록과 설정을 유지할 수 있습니다.

ADB 지침은 함께 배포하는 `halcam-cli-0.28.0-SKILL.md`를 사용하세요. APK와 스킬 파일의 SHA-256은 `SHA256SUMS.txt`에 제공합니다.

## 확인 범위

JVM·문서·기기 검사와 업데이트 결과는 [0.28.0 검증 기록](../validation/release-0.28.0.md)에 있습니다. Android 8·8.1 실기기, 실제 OS 백업 복원, 대화면 회전, 다른 제조사·세 카메라 이상·장시간 녹화는 이번 검증에 포함되지 않습니다.

사용 방법은 [Live 가이드](https://ttolsun.github.io/hal-camera/live.html)를 참고하세요.
