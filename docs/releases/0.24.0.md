# HAL CAM 0.24.0

**Video를 고르고 녹화하면서 줌을 바꿔 보세요.** 이번 버전은 녹화 출력을 미리 준비하고, 녹화 중 사진과 PIP 촬영을 Photo와 같은 조작 방식으로 정리했습니다.

## 바로 해 볼 세 가지

1. `Video → 녹화` 후 1배 → 2배 → 1배로 바꿉니다. 핀치와 줌 버튼 모두 녹화 중에 동작합니다.
2. 녹화 중 셔터 오른쪽 사진 버튼을 누릅니다. 일반 녹화는 카메라 JPEG 또는 YUV 변환 JPEG, PIP는 합성 JPEG를 저장합니다.
3. Camera2에서 `M → WB → WB 값 버튼`을 누릅니다. 버튼 아래 목록에서 Daylight와 Incandescent를 번갈아 선택해 같은 장면의 색을 비교합니다.

## 달라진 점

- **녹화 시작:** Video에 들어갈 때 출력을 준비합니다. 녹화 버튼에서는 카메라 세션을 다시 구성하거나 CameraX use case를 다시 bind하지 않습니다.
- **PIP와 Multi:** PIP는 보조 영상을 한 파일에 합성하고, Multi는 독립 카메라별 파일을 저장합니다. 지원 조합에서 사용할 수 있으며 Multi 영상은 무음입니다.
- **촬영 모드:** Video에서는 DNG를 끄고, Photo에서는 손떨림 보정을 Off로 고정합니다. 모드·엔진을 바꾸면 촬영 설정을 초기화합니다.
- **안정성:** 준비된 인코더의 오류도 자원을 해제하고 복구합니다. PIP는 기존 인코더 해제 후 다음 녹화를 준비합니다. 명시적인 EIS 녹화에서 확인한 버퍼 전달 오류도 수정했습니다.
- **설명과 화면:** WB를 연결된 목록으로 바꾸고, Live 정보와 줌 표시를 정리했습니다. 사용 가이드는 촬영 절차를 먼저 보여 주며 구현 상세는 필요한 곳에서 펼칩니다.

## 업데이트

`HAL-Camera-0.24.0.apk`를 기존 앱 위에 설치하세요. 앱을 삭제할 필요가 없습니다. 패키지는 `dev.halcamera`, versionCode는 `670`이며 Android 8.0 이상을 지원합니다. PIP·Multi는 Android 11 이상과 지원되는 기기 조합이 필요합니다.

ADB 사용 지침은 첨부한 `halcam-cli-0.24.0-SKILL.md`입니다. 이 태그의 `skills/halcam-cli/SKILL.md`와 같은 파일입니다. 선택 도구인 Python CLI 0.3.0은 `halcamera-cli-0.3.0.zip`으로 제공하며 기본 사용에는 ADB만 필요합니다. 파일 해시는 `SHA256SUMS.txt`에서 확인하세요.

## 확인한 범위와 제한

JVM 764개(app 752개·ctsvendor 12개), lint와 정식 빌드가 통과했습니다. 기존 정식 인증서와 동일한 서명을 확인하고 기기의 CLI hello에서 0.24.0을 확인합니다.

Galaxy S25+ (SM-S936N), Android 16/API 36에서 PHOTO 보정 2개와 VIDEO 10개 조합, 녹화 중 줌·스냅샷, PIP 연속 녹화와 WB 조작을 확인했습니다. 준비 완료 인코더 오류는 실제 인코더·세션에 오류 콜백을 주입해 해제와 프리뷰 복구를 검사했습니다.

세션을 유지한다는 결과가 화면 프레임 누락이 전혀 없다는 뜻은 아닙니다. CameraX 스냅샷은 일부 기기에서 영상 프레임 간격을 늘릴 수 있습니다. PIP 스냅샷은 합성 해상도를 사용하며 일반 JPEG/YUV 크기 선택과 별개입니다. 다른 제조사 기기, 전체 CTS와 장시간 Benchmark는 이번 배포 검증 범위에 포함하지 않았습니다.
