# HAL CAM 0.10.1

Camera HAL 개발자의 관측·재현·비교 흐름에 맞춰 화면과 설명을 정리했습니다.

## 설치

첨부된 `HAL-Camera-0.10.1.apk`를 기존 앱 위에 설치하세요. 실행 기록과 baseline을 유지하려면 앱을 삭제하지 마세요.

기존 설치본의 versionCode 111에서 업데이트할 수 있도록 112로 올렸습니다. APK 해시는 첨부된 `SHA256SUMS.txt`에서 확인할 수 있습니다.

## 변경 사항

- Live 하단에 투명한 Mark ZIP 버튼을 고정했습니다. 상단·하단에 은은한 그라데이션을 두고 촬영 조작부부터 Mark까지 하단 음영이 자연스럽게 이어지도록 했습니다. Benchmark는 도구 메뉴에서만 엽니다.
- 진단 패널에서 상단 프리뷰를 유지하고 프레임 간격 그래프를 먼저 표시합니다. 상세 수치와 ADB CLI 설정은 펼쳐 봅니다.
- Benchmark 결과는 회귀 지표를 먼저 보여 줍니다. 가로 스크롤 대신 줄바꿈하는 행으로 값·max/p95·변화량·판정 사유를 표시합니다.
- Results에 두 실행 비교 버튼과 행별 작업 메뉴를 추가했습니다. 반복 측정 비교에는 A/B 기기·빌드·실행 수 요약을 표시합니다.
- CTS·Probe·Benchmark의 반복 설명을 줄였습니다. 공식 CTS 결과와의 구분, 중단 시 FAIL 처리, 측정 범위와 비교 조건은 유지했습니다.

측정 계약·지표 계산·회귀 규칙과 저장 형식은 유지합니다. PC CLI는 0.2.0을 계속 사용합니다.

## 검증

서명된 Release 빌드, JVM 테스트 407개, PC CLI 테스트 23개, 문서 회귀 테스트 18개와 전체 문서 검사가 통과했습니다. 앱 lint는 오류 0개, 경고 109개입니다. Galaxy S25+에서 기존 앱 위 업데이트와 최종 화면을 확인했습니다. 상세 결과는 [UI 검토 기록](../reviews/hal-developer-ui-20260919/README.md)에 기록합니다. 회귀 강조용 합성 샘플은 실제 성능 결과가 아닙니다.
