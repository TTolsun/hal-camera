# HAL CAM 0.20.0

ADB만으로 앱과 같은 벤치마크를 실행하고 결과 JSON을 회수할 수 있습니다. 진행 화면은 현재 작업과 대기 시간, 촬영·녹화 회차를 표시합니다.

## Installation

`HAL-Camera-0.20.0.apk`를 기존 앱 위에 설치합니다. 패키지는 `dev.halcamera`, versionCode는 `629`이며 Android 8.0 이상을 지원합니다. 기존 정식 인증서로 서명하며 파일 해시는 `SHA256SUMS.txt`에 제공합니다. 기존 앱을 삭제하지 않고 업데이트하면 저장 데이터를 유지합니다.

## Changes

- `benchmark run --camera 0`으로 Camera2 표준 v2 벤치마크를 실행하고 schema 5 JSON을 회수합니다. 기본 실행 제한은 600초입니다. Live 카메라 종료 후 기존 벤치마크 화면·Runner·저장 경로를 사용합니다.
- `doctor`로 기본 설정을 진단하고 `status --app`으로 현재 앱 상태를 조회합니다. 권한·잠금·CLI 허용 오류와 여러 기기 연결 시 대응 안내를 보강했습니다.
- ADB 스크립트가 성공하지 않은 완료 상태를 성공으로 안내하지 않도록 수정했습니다. Python CLI는 선택 도구이며 벤치마크 명령도 제공합니다.
- Recording의 프레임 수를 현재 녹화 회차의 카메라 결과 콜백으로 집계합니다. 녹화 회차와 경과 시간, 회차 내 진행률을 표시합니다.
- 다른 벤치마크 단계에도 짧은 상황 설명을 추가했습니다. 워밍업·관측 시간, 사진 촬영 순서와 저장 상태를 제목 아래의 보조 줄에서 확인합니다.

## Validation

Galaxy S25+ (`SM-S936N`)·Android 16의 후면 카메라 0에서 정상 완료, 타임아웃, 취소, 화면 이탈, 중복·충돌·BUSY 및 잘못된 인자를 확인했습니다. 녹화 다섯 회차의 실제 프레임 증가와 단계 설명의 표시도 확인했습니다. 기기별 스트림 지원과 큰 글꼴 설정까지 검증한 것은 아닙니다.

자세한 결과는 [CLI 검증](../validation/cli-benchmark-20261006.md), [녹화 진행 검증](../validation/benchmark-recording-progress-20261006.md), [단계 설명 검증](../validation/benchmark-step-detail-20261006.md)에 있습니다. 실행 방법은 [CLI 가이드](../../guide/cli.md)를 확인하세요.
