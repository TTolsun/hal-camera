# HAL CAM 0.14.0

Live의 Flash·AF·AE 잠금·EV 제어를 추가하고, 프리뷰를 가리는 조작부를 줄였습니다. 앱을 열면 바로 프리뷰가 나오며 상단 중앙의 화살표로 촬영 제어를 펼칩니다.

## 설치

첨부된 `HAL-Camera-0.14.0.apk`를 기존 앱 위에 설치하세요. 기존 정식 버전과 같은 인증서로 서명했으며, 앱을 삭제하지 않고 업데이트하면 앱 데이터와 실행 기록을 유지합니다.

| 항목 | 값 |
| --- | --- |
| 패키지 | `dev.halcamera` |
| 버전 | `0.14.0` · versionCode `513` |
| 지원 Android | Android 8.0 이상 · minSdk 26 / targetSdk 36 |
| 빌드 | 서명된 Release · debuggable=false |
| 인증서 SHA-256 | `f2432413635645cc35e674e498e88ff518abb878065c21f17bb3c2128487b5c1` |

현재 시험 기기에 설치된 임시 빌드가 versionCode 512이므로 정식 번호를 513으로 올렸습니다. APK의 SHA-256은 첨부된 `SHA256SUMS.txt`와 대조할 수 있습니다.

## 변경 사항

- Live에 Flash Off·Auto·On·Torch, AF 잠금, AE 잠금, EV 다이얼과 `− / + / 0` 조절을 제공합니다. 카메라가 지원하는 범위와 제어만 사용할 수 있으며 녹화 중 줌도 유지합니다. [PR #183](https://github.com/TTolsun/hal-camera/pull/183)
- 상단 중앙의 카메라 이름·Live 문구를 없애고 촬영 제어 화살표만 표시합니다. API 이름 아래의 작은 원과 Live 글씨는 프리뷰 동작 중에 함께 빨간색으로 깜빡이고 정지하면 회색으로 고정됩니다. 시스템 애니메이션이 꺼져 있으면 동작 중에도 빨간색을 고정합니다. [PR #187](https://github.com/TTolsun/hal-camera/pull/187)
- 도구 메뉴에서 선택적으로 여는 작업실에 기기 정보와 기능 진입점을 모았습니다. 앱의 최초 화면은 계속 Live입니다. 촬영 제어와 EV 패널을 작게 정리하고, 실행 기록의 필터를 접어두며 중단·무효 실행도 기본 목록에 포함합니다. CTS 실행 중 결과 복사·공유는 비활성화합니다. [PR #186](https://github.com/TTolsun/hal-camera/pull/186)
- 벤치마크의 두 실행 비교를 결과 화면의 막대와 눈금으로 통합했습니다. 실행 기록의 중복 버튼과 카메라 이름을 줄이고 baseline을 제목 아래에 모았습니다. [PR #182](https://github.com/TTolsun/hal-camera/pull/182), [PR #166](https://github.com/TTolsun/hal-camera/pull/166), [PR #164](https://github.com/TTolsun/hal-camera/pull/164)
- S25+ v2 점수 민감도 재검증 결과를 문서와 회귀 테스트에 반영했습니다. [PR #161](https://github.com/TTolsun/hal-camera/pull/161)

## 검증

정식 APK 빌드, JVM 테스트 492개와 Android lint가 통과했습니다. 현재 사용 기기인 Galaxy S25+ SM-S936N / Android 16에 배포 APK 자체를 `adb install -r`로 설치했습니다. versionCode 512에서 513으로 업데이트되었고 최초 설치 시각이 유지됐으며, 설치 직후 Camera2 프리뷰와 Live 표시를 확인했습니다.

UI 검토에서는 같은 기기의 Camera2·CameraX 전환, 일시정지·재개, 홈 화면 복귀, Flash 선택지, AF·AE 잠금과 EV 패널을 확인했습니다. 검증 범위는 현재 S25+로 한정합니다. 이번 릴리스 준비에서 전체 CTS 및 벤치마크를 다시 실행하지는 않았습니다.

[상단 UI 검증 기록](../validation/live-header-2026-09-27.md)에서 상세 시나리오와 한계를 확인할 수 있습니다.
