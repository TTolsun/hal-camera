# HAL CAM 0.18.0

Camera2 Live에서 ISO·노출 시간·초점·화이트밸런스를 직접 조절할 수 있습니다. 입력한 요청과 카메라가 실제 적용한 결과를 구분해 확인하며, 사진과 녹화에도 같은 설정을 적용합니다.

## Installation

`HAL-Camera-0.18.0.apk`를 기존 앱 위에 설치합니다. 패키지는 `dev.halcamera`, versionCode는 `627`이며 Android 8.0 이상을 지원합니다. 기존 정식 인증서로 서명합니다. 앱을 삭제하지 않고 업데이트하면 기존 실행 데이터와 설정을 유지합니다. 배포 파일의 해시는 `SHA256SUMS.txt`에 제공합니다.

## Changes

- `Manual` 패널은 `ISO`, `Shutter`, `Focus`, `WB` 중 하나만 펼쳐서 조절합니다. 슬라이더와 직접 입력을 제공하며, 잘못된 입력은 대화상자를 유지하고 지원 범위를 안내합니다.
- 자동 노출에서 시작할 때 현재 관측값을 지원 범위로 제한하고 변경 사유를 알립니다. 노출 시간은 센서 범위와 FPS 정책으로 제한하며 실제 ISO·노출 시간·FPS를 확인할 수 있습니다.
- 요청 숫자와 실제값의 중복 표시를 줄였습니다. `Hide`는 설정을 유지하고, `Reset`은 노출·초점·WB를 자동으로 되돌립니다. 제목과 버튼은 영어, 수동 제어의 설명과 오류는 한글로 표시합니다.
- 수동 WB는 지원 프리셋과 gains·3×3 행렬을 제공합니다. 수동 gains는 지원 기기의 수동 노출에서만 사용하며 Kelvin 변환을 제공하지 않습니다.
- CameraX에는 미지원 사유와 Camera2로 전환하는 기존 상단 버튼의 위치를 안내합니다. Benchmark의 profile·측정 계약은 유지합니다.
- 이전 릴리스 이후 main에 반영된 녹화 중 JPEG 촬영(#212)과 Live 촬영 조작부 개선(#214)을 포함합니다.

## Validation

Galaxy S25+(SM-S936N, Android 16)에서 수동 ISO·노출·초점·WB, 자동 복귀, 사진 쌍 저장, 녹화와 녹화 중 JPEG, CameraX 전환을 확인했습니다. 글꼴 배율 1.15와 1.5에서 수동 ISO 패널의 탭·제목·실제값 표시를 확인했습니다.

앱 JVM 테스트 612개와 Android lint를 검증합니다. 구체적인 장면·관측값은 [수동 촬영 기록](../validation/manual-capture-20261001.md)에 있습니다. 색 정확도·초점 해상력과 다른 제조사 기기는 검증하지 않았습니다.
