# HAL CAM 0.13.2

화면을 옮겨 다닐 때 매번 다시 찾아야 하던 것들을 한 규칙으로 맞춘 판입니다. 뒤로 가기 버튼이 모든 화면에서 같은 자리에 있고, Benchmark 계열의 버튼과 메뉴가 앱의 다른 화면처럼 한국어로 적히며, 사진과 동영상의 저장 안내가 같은 자리에 뜹니다. 0.13.1과 같은 수동 검토에서 나온 나머지 이슈들입니다.

## 설치

첨부된 `HAL-Camera-0.13.2.apk`를 기존 앱 위에 설치하세요. 앱 데이터와 실행 기록을 유지하려면 앱을 삭제하지 마세요.

| 항목 | 값 |
| --- | --- |
| 패키지 | `dev.halcamera` |
| 버전 | `0.13.2` · versionCode `146` |
| 지원 Android | Android 8.0 이상 · minSdk 26 / targetSdk 36 |
| 빌드 | 서명된 Release |
| 인증서 SHA-256 | `f2432413635645cc35e674e498e88ff518abb878065c21f17bb3c2128487b5c1` |

저장 형식은 그대로입니다. run JSON은 schema 5, profile은 `camera2-standard-v2`이며 baseline과 calibration을 다시 만들 필요가 없습니다. 화면에 적히는 이름만 바뀌었고 파일에 기록하는 필드와 값은 바뀌지 않았습니다.

## 변경 사항

### 뒤로 가기가 모든 화면에서 같은 자리

- 같은 깊이의 화면인데 빠져나가는 버튼이 다섯 가지 자리에 있었습니다. 갤러리는 제목 왼쪽 `<`, Probe와 실행 기록은 제목 아래 줄의 `<`, CTS 네 화면은 오른쪽 위 `X`, Benchmark는 화면 아래 카메라 선택 버튼 옆 `X`, 비교 화면은 맨 아래 `<`였습니다.
- 이제 Live 아래의 모든 화면이 갤러리처럼 화면 제목 왼쪽에 `<`를 둡니다. 공통 제목 줄은 `Look.titleBar` 하나가 만듭니다.
- 벤치마크가 실행 중일 때는 이 아이콘을 표시하지 않습니다. 실수로 눌러 측정이 끝나는 일을 막기 위해서이며, 실행 중에는 `중단`으로만 멈춥니다.

### Benchmark 계열의 버튼과 메뉴를 한국어로

- 실행 기록의 `⋮` 메뉴 일곱 항목 중 한국어는 `결과 열기`와 `취소` 둘뿐이었습니다. 이제 `baseline으로 지정`, `비교`, `JSON 내보내기`, `CSV 내보내기`, `삭제`까지 모두 한국어입니다.
- 시작 카드의 `Start benchmark`·`History`·`Settings`는 `벤치마크 시작`·`실행 기록`·`설정`이 되었고, 결과 화면의 `Compare`·`Export`·`New run`은 `비교`·`내보내기`·`다시 실행`이 되었습니다. 보관 한도 설정은 `보관 개수`, 한도 없음은 `무제한`으로 적습니다.
- `History` 버튼을 누르면 제목이 `Results`인 화면이 열려서, 누른 이름과 도착한 화면의 이름이 달랐습니다. 이제 둘 다 `실행 기록`입니다.
- 지표 이름(`Open · median`), 판정 단어(`No baseline`, `degraded`), 상태 칩(`Thermal OK`)은 영어로 남겼습니다. 이 이름들은 run JSON과 CLI 출력에 같은 철자로 기록되므로, 화면과 파일을 오가며 같은 이름으로 찾을 수 있어야 하기 때문입니다. `baseline`도 같은 이유로 버튼 안에서 원어를 유지합니다.
- 0.12.0에서 정한 "라벨과 버튼은 영어" 규칙을 이번에 바꾼 것이며, [Benchmark 문서](https://github.com/TTolsun/hal-camera/blob/main/guide/benchmark.md)가 새 규칙과 이유를 적습니다([PR #151](https://github.com/TTolsun/hal-camera/pull/151)).

### 도구 메뉴와 저장 안내

- 상단 `도구` 메뉴의 Probe · CTS · Benchmark에 라디오 버튼이 붙어 있었고, 선택된 항목이 없으니 세 개 모두 빈 원이었습니다. 이 메뉴는 값을 고르는 것이 아니라 화면을 여는 것이므로 이제 이름만 표시합니다.
- 사진을 저장하면 화면 위쪽에 안내 문구가 떴는데, 동영상은 화면 아래쪽 토스트로 떠서 사진·동영상 모드 버튼을 가렸습니다. 이제 동영상 저장 안내도 사진과 같은 위쪽 줄에 뜹니다.
- 처음 고친 코드로는 동영상 안내가 기기에서 보이지 않았습니다. 녹화가 끝나면 프리뷰 세션을 다시 만들면서 `LIVE` 상태가 보고되는데, 이 보고가 방금 띄운 안내를 곧바로 숨겼기 때문입니다. 저장 안내는 이제 그 보고가 와도 2.5초 동안 남고, 실패 안내처럼 다른 문구는 여전히 바로 표시됩니다([PR #151](https://github.com/TTolsun/hal-camera/pull/151)).

### 진단 패널과 다이얼로그

- 진단 패널의 `기록 목록`에서 incident를 누르면 뜨는 다이얼로그에 닫는 버튼이 없었습니다. `삭제`가 들어 있는 목록이라 `취소` 버튼을 붙였습니다. 첫 항목의 이름도 `공유 / Google Drive`에서 `공유`로 바꿨습니다. 실제로는 시스템 공유 시트가 열리므로 Drive만 지목할 이유가 없었습니다.
- 시스템 줄에서 CPU와 PSS에는 레이블이 붙는데 Thermal만 `NONE` 같은 값만 남아, 무엇의 값인지 알 수 없었습니다. 이제 `Thermal NONE`으로 적습니다.
- Mark 저장 다이얼로그가 공백으로 열을 맞추려 했지만, 다이얼로그 본문은 비례 글꼴이라 정렬이 어긋나고 `(기준 p50 …)`이 다음 줄로 밀렸습니다. 이제 한 줄에 값 하나씩 적습니다([PR #148](https://github.com/TTolsun/hal-camera/pull/148)).
- `App CPU 32.7%*`의 `*`를 설명하는 문장이 `측정 안내` 다이얼로그 안에만 있었습니다. 이제 줄 자체가 `App CPU 24.7% (1코어=100%)`로 척도를 밝히므로, 150%가 나와도 이상으로 읽히지 않습니다. 척도를 넣으면 세 값이 한 줄에 들어가지 않아 `NONE`만 다음 줄로 넘어갔기 때문에, 첫 줄에 CPU, 둘째 줄에 PSS·Thermal을 두도록 줄을 직접 나눴습니다([PR #154](https://github.com/TTolsun/hal-camera/pull/154)).

### 문서

- [디자인 문서](https://github.com/TTolsun/hal-camera/blob/main/docs/design/APP-UI.md)가 배치·흐름·상태·색상을 그림으로 보여 주고([PR #149](https://github.com/TTolsun/hal-camera/pull/149)), Live 화면 그림을 실제 캡처로 바꿨습니다([PR #153](https://github.com/TTolsun/hal-camera/pull/153)).
- 화면 조작 규칙(도구 메뉴의 화면 전환, 줌, 카메라 이름)을 `.omm` 요소로 추적해, 관련 코드가 바뀌면 문서 검사가 그림을 다시 확인하게 했습니다([PR #150](https://github.com/TTolsun/hal-camera/pull/150)).

## 검증 범위

[PR #148](https://github.com/TTolsun/hal-camera/pull/148)·[#151](https://github.com/TTolsun/hal-camera/pull/151)·[#154](https://github.com/TTolsun/hal-camera/pull/154)의 Android 빌드·단위 테스트·Lint, CLI 테스트와 문서 CI가 통과했습니다.

Galaxy S25+(`SM-S936N`)의 Android 16에서 각 PR의 release 빌드로 직접 확인한 항목은 다음과 같습니다.

- Probe, CTS, Benchmark, 실행 기록 화면이 모두 제목 왼쪽에 `<`를 표시하고, CTS 화면의 `<`로 Live에 돌아옵니다.
- 도구 메뉴가 라디오 버튼 없이 세 이름만 표시합니다.
- 시작 카드, 결과 화면, 실행 기록의 `⋮` 메뉴가 한국어 라벨을 표시하고, 실행 기록 화면의 제목이 버튼 이름과 같습니다.
- 동영상을 녹화하고 멈추면 `갤러리에 동영상을 저장했습니다`가 위쪽 안내 줄에 뜹니다.
- Incident 액션 다이얼로그에 `취소`가 있고 누르면 Live로 돌아옵니다. 시스템 줄이 `Thermal NONE`을 적고, Mark 저장 다이얼로그가 줄바꿈 없이 한 줄에 값 하나씩 적습니다.
- 시스템 줄이 `App CPU 24.7% (1코어=100%)`와 `PSS 176 MB · Thermal NONE` 두 줄로 나뉘고, `측정 안내`의 설명에서 `*`가 빠졌습니다.

확인하지 못한 항목은 두 가지입니다. 벤치마크 비교 화면의 `<`는 비교할 baseline 실행이 기기에 없어 열어 보지 못했으므로 코드 확인에 머물렀습니다. 저장이 끝나기 전에 카메라가 닫히는 경우의 토스트는 재현하기 어려워 코드 확인에 머물렀습니다.
