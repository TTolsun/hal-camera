# HAL CAM 0.27.0

**Multi를 Photo와 같은 흐름으로 조작하면서 카메라별 크기와 배치를 유지합니다.** 기본은 Side by side이며 카메라 ID를 길게 눌러 끌면 배치와 순서를 바꿀 수 있습니다.

## 달라진 점

- 선택한 카메라 ID에 흰 테두리와 체크를 표시하고 Live의 해당 크기를 강조합니다. 카메라 수와 관계없이 크기를 한 줄씩 표시합니다.
- Sizes에서 카메라별 Preview와 JPEG 크기를 나란히 고릅니다. Split의 미지원 조합은 펼쳐서 확인할 수 있으며 별도 레이아웃 선택은 없습니다.
- Multi P/V는 같은 조작 구성을 사용하고, 전환할 때 기존 세션이 닫힌 뒤 스트림을 다시 구성합니다. 카메라별 FPS/EXP와 선택한 크기를 유지합니다.
- 선택창의 중복 상태 처리를 공통화하고 미사용 아이콘 5개를 제거했습니다. README·상태·Callback 문서의 낡은 Multi 설명을 정리했습니다.
- 홈페이지의 Camera HAL 소개 영상과 장면 설명을 갱신했습니다.

## 업데이트

`HAL-Camera-0.27.0.apk`를 기존 앱 위에 설치하세요. 패키지는 `dev.halcamera`, versionCode는 `681`이며 기존 정식 인증서를 사용합니다. 앱을 삭제할 필요가 없습니다.

ADB 지침은 첨부한 `halcam-cli-0.27.0-SKILL.md`를 사용하세요. 첨부 파일 해시는 `SHA256SUMS.txt`에 제공합니다.

## 확인 범위

코드·문서 구조 검토와 정식 APK 검사 결과는 [0.27.0 검증 기록](../validation/release-0.27.0.md)에 모았습니다. Multi는 Android 11 이상과 기기가 지원하는 독립 카메라 조합이 필요하며, 영상은 무음입니다. 세 카메라 이상·다른 제조사·장시간 녹화는 별도 검증이 필요합니다.
