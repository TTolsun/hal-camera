# HAL CAM 0.29.1

**Multi V에서 오디오가 영상보다 약 0.3초 먼저 끝나는 문제와 시작 시각 정렬을 개선했습니다.** Camera2와 CameraX가 같은 녹화 경로를 사용합니다.

## 달라진 점

- 모든 카메라의 영상 입력을 먼저 멈춘 뒤 마이크와 인코더를 마무리합니다. 오디오 종료를 기다리는 동안 영상만 계속 길어지지 않습니다.
- 마이크의 하드웨어 시각과 실제 인코딩된 첫 영상 프레임의 시각을 기준으로 각 원본의 오디오를 정렬합니다. 기기별 고정 보정값이나 소리 늘이기를 적용하지 않습니다.
- 마이크 준비·종료는 별도 작업 스레드에서 처리합니다. 시각을 확보하지 못하거나 인코딩·결합이 실패하면 무음 성공으로 처리하지 않습니다.
- Multi P/V 전환의 스트림 재구성, 카메라별 크기·FPS/EXP, 카메라 ID 이동과 독립 원본 저장을 유지합니다.

## 업데이트와 한계

`HAL-Camera-0.29.1.apk`를 기존 앱 위에 설치하세요. 패키지는 `dev.halcamera`, versionCode는 `684`이며 기존 정식 서명을 사용합니다. 앱을 삭제하지 않아야 기존 기록과 설정을 유지할 수 있습니다.

Galaxy S25+의 박수 시험에서 영상·오디오 끝 시각의 차이는 네 파일 모두 21ms 이내였습니다. 실제 손 접촉과 소리에는 대략 30~80ms의 잔여 오차가 관찰됐으므로 완전한 동기를 보장하는 릴리스는 아닙니다. 기존 영상은 변경하지 않습니다.

측정 방법과 기기 제약은 [0.29.1 검증 기록](../validation/release-0.29.1.md), 사용법은 [Live 가이드](https://ttolsun.github.io/hal-camera/live.html)를 참고하세요.
