# HAL CAM 0.6.0

PC 터미널에서 HALCamera의 사진 촬영과 벤치마크를 실행하고 결과를 회수할 수 있습니다. 0.5.1의 카메라·갤러리 UI를 유지합니다.

## 설치

`HAL-Camera-0.6.0.apk`는 기존 정식 버전과 같은 인증서로 서명했습니다. 기존 앱 위에 업데이트할 수 있으며 Android 8.0 이상을 지원합니다. package는 `dev.halcamera`, versionCode는 `9`, targetSdk는 `36`이며 Release는 debuggable=false입니다.

Python 3.11 이상과 Android Platform Tools를 설치한 PC에서 첨부 wheel을 설치합니다.

```sh
python -m pip install halcamera_cli-0.1.0-py3-none-any.whl
halcam devices
halcam --serial DEVICE_SERIAL doctor --json
halcam --serial DEVICE_SERIAL capture --camera 0 --output ./photos
halcam --serial DEVICE_SERIAL benchmark run --camera 0 --output ./runs
```

기기의 ADB 연결을 승인하고 앱의 **Benchmark → ADB CLI 허용**을 켭니다. 화면 잠금을 해제하고 카메라 권한을 허용합니다. Android 8–9의 사진 저장에는 저장소 권한도 필요합니다.

## 동작과 복구

- `devices`, `doctor`, `launch`, `cameras`, `preview`, `capture`, `benchmark run`, `status`, `cancel`, `fetch`를 제공합니다.
- `--json`과 종료 코드로 접수·완료·실패·시간 초과를 구분합니다. `--no-wait`는 접수만 기다립니다.
- 요청 ID를 먼저 저장합니다. 같은 내용으로 다시 제출하면 기존 상태를 반환하며, 앱 프로세스가 종료된 미완료 요청은 `interrupted`로 복구합니다.
- 사진 두 장과 benchmark JSON은 크기·SHA-256 검증 후 PC에 저장합니다. 다운로드 실패 시 `fetch REQUEST_UUID --output ./results`로 다시 가져옵니다.
- UI와 CLI 작업이 겹치면 `BUSY`로 거부합니다. 사진 저장이 이미 진행 중이면 실제 결과를 보존하고, benchmark 취소·화면 종료에는 partial 보고서를 회수할 수 있습니다.

## 검증과 범위

Python 18개, JVM 267개, API 26·36의 저장소 instrumentation 15개씩, Debug·Release 빌드와 lint를 확인했습니다. Galaxy S25+ / Android 16에서 USB·무선 사진 회수, 벤치마크, 취소·시간 초과·프로세스 종료 복구와 기존 UI 사진·동영상·갤러리를 확인했습니다. UI·CLI를 번갈아 각각 5회 실행한 결과는 같은 측정 계약과 20개 지표를 유지했습니다. 이를 성능 동등성의 증명으로 해석하지 않습니다.

Windows는 실제 기기 연결을 검증했고 Linux·macOS는 CLI 테스트와 wheel 설치 CI 범위입니다. 사용자 0의 전면 앱을 지원합니다. CLI 녹화·줌·CameraX 제어·baseline 변경·이력 삭제는 후속 범위입니다. 기록은 완료 후 최대 24시간·200개를 보존하며 원본 미디어를 삭제하지 않습니다.
