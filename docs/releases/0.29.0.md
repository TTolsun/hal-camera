# HAL CAM 0.29.0

**CameraX Multi 촬영과 Multi V의 마이크 녹음을 추가했습니다.** Camera2와 CameraX 모두 카메라별 원본 영상에 같은 마이크 소리를 저장합니다.

## 달라진 점

- Multi에서 Camera2와 CameraX를 선택할 수 있습니다. CameraX는 기기가 광고한 동시 조합의 최대 두 카메라를 사용합니다.
- Multi V는 마이크 권한을 요청하고 AAC 오디오를 각 MP4에 넣습니다. 녹음이나 저장이 실패하면 무음 성공으로 처리하지 않습니다.
- Multi P/V 전환 시 스트림 재구성, 카메라별 크기·FPS/EXP, 카메라 ID 드래그와 카메라별 JPEG 저장은 유지합니다.
- 두 엔진이 녹화·오디오 결합·실패 처리를 공유하도록 분리하고, 오디오 시각 정렬 회귀 테스트를 추가했습니다.

## 업데이트

`HAL-Camera-0.29.0.apk`를 기존 앱 위에 설치하세요. 패키지는 `dev.halcamera`, versionCode는 `683`이며 기존 정식 서명을 사용합니다. 앱을 삭제하지 않아야 실행 기록과 설정을 유지할 수 있습니다.

기존 무음 영상의 소리가 복원되지는 않습니다. 새로 녹화한 영상부터 소리가 포함됩니다. 카메라별 독립 마이크 녹음이나 센서 동기 촬영은 제공하지 않습니다.

검증 범위와 제약은 [0.29.0 검증 기록](../validation/release-0.29.0.md), 사용법은 [Live 가이드](https://ttolsun.github.io/hal-camera/live.html)를 참고하세요.
