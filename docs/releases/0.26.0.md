# HAL CAM 0.26.0

**화면은 나눠 보고, 파일은 각각 남기세요.** Multi P·V가 Photo·Video와 같은 조작 흐름을 사용하며, Split으로 배치와 카메라를 고릅니다. 각 파일에는 자기 카메라의 전체 영상만 들어갑니다.

## 바로 해 볼 세 가지

1. `Multi · P → Split`에서 전면·후면 조합을 고르고 `Apply`를 누릅니다. 한 번 찍은 뒤 갤러리에서 두 원본을 확인하세요.
2. Split을 위아래에서 좌우로 바꿔 다시 찍습니다. 배치는 바뀌어도 파일의 크기와 전체 구도는 유지됩니다.
3. `Multi · V`로 녹화하다 오른쪽 사진 버튼을 누릅니다. 사진을 저장하는 동안 두 영상은 계속 녹화됩니다.

## 달라진 점

- **조작:** Manual을 제외하고 줌·터치 초점·AF·AE·EV를 제공합니다. Callback의 ID로 장치를 바꾸며, Gallery·Lab 복귀 후 프리뷰를 복원합니다.
- **코드:** Split 선택 규칙·설정창·장치 조회를 분리했습니다. 사용하지 않는 Multi PIP 경로와 중복 버튼 구성을 정리했고, 저장 실패는 문자열 대신 결과 상태로 전달합니다.
- **문서:** PIP와 Multi의 저장 결과를 구분했습니다. 짧은 따라 하기와 확인할 결과를 먼저 보여주며 내부 동작은 펼쳐서 읽습니다. 낡은 Callback·Multi PIP 설명을 수정했습니다.

## 업데이트

`HAL-Camera-0.26.0.apk`를 기존 앱 위에 설치하세요. 패키지는 `dev.halcamera`, versionCode는 `672`입니다. 같은 정식 인증서로 서명하며 기존 데이터를 유지합니다.

ADB 지침은 이 태그의 `halcam-cli-0.26.0-SKILL.md`입니다. 선택 도구인 Python CLI는 0.3.0을 유지합니다. 첨부 파일 해시는 `SHA256SUMS.txt`에 있습니다.

## 확인 범위

Galaxy S25+ · Android 16에서 실제 버튼 조작과 카메라별 JPEG·MP4를 확인했습니다. JVM·lint·문서 검사와 구조 검토는 [0.26.0 검증 기록](../validation/release-0.26.0.md)에 있습니다.

Multi는 Android 11 이상과 기기가 지원하는 독립 장치 조합이 필요합니다. Camera2로 동작하며 영상은 무음, 플래시는 Off·Torch입니다. Manual·AEB와 센서 동기 촬영은 제공하지 않습니다. 세 카메라 이상, 다른 제조사와 장시간 녹화는 이번 기기 검증 범위에 포함하지 않습니다.
