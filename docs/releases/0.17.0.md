# HAL CAM 0.17.0

Gallery와 About에 Runway 스타일을 적용하고 Lab의 설정·ZIP 대화상자를 Apple 스타일로 정리했습니다. About의 기존 로봇 캐릭터는 유지합니다. Live 스트림 표시와 CameraX CLI 크기 설정도 포함합니다.

## 설치

첨부된 `HAL-Camera-0.17.0.apk`를 기존 앱 위에 설치하세요. 패키지는 `dev.halcamera`, versionCode는 `594`이며 Android 8.0 이상을 지원합니다. 기존 정식 인증서로 서명하므로 앱을 삭제하지 않고 업데이트하면 데이터를 유지합니다. 파일 해시는 `SHA256SUMS.txt`에서 확인할 수 있습니다.

## 변경 사항

- Gallery는 어두운 미디어 격자, 둥근 썸네일과 흰색 기본 버튼을 사용합니다. 선택·사진 상세·공유·삭제의 기존 동작을 유지하며 첫 타일의 모서리 누락을 수정했습니다.
- About은 기존 로봇 캐릭터와 실제 버전·연락처를 유지하면서 흰 배경과 검은 버튼을 사용합니다. Device Info·ADB CLI·ZIP 목록과 파일 작업·삭제 확인은 Apple 기반 공통 대화상자로 정리했습니다.
- Live의 이벤트 저장 버튼은 `Save Events · ZIP`, 저장 대기는 `Saving in …s`로 표시합니다. Live 표시 옆에 실제 P·Y·J 스트림 크기를 표시하며 녹화 중에는 P·R과 코덱을 표시합니다. 크기 영역을 눌러 Live Streams를 열 수 있습니다.
- CameraX의 Live 스트림과 CLI 크기 설정을 보완했습니다. 요청·실제 출력 계약과 검증 범위는 [Live 스트림·CameraX CLI 기록](../validation/live-streams-camerax-cli.md)을 참고하세요.
- launch 모드 조사용 CPU·Perfetto 진단 도구와 분석 기록을 포함합니다. 이번 조사는 기기별 원인 분석이며 모든 환경에서 성능이 개선됐다는 의미는 아닙니다.

관련 변경: [PR #208](https://github.com/TTolsun/hal-camera/pull/208), [PR #209](https://github.com/TTolsun/hal-camera/pull/209), [PR #210](https://github.com/TTolsun/hal-camera/pull/210).

## 검증 범위

PR #210에서 Android 빌드·JVM 테스트·lint, Ubuntu·Windows 문서 검사와 세 운영체제의 Python CI가 통과했습니다. 최신 main 통합 후 앱 JVM 테스트 599개를 확인했습니다. Galaxy S25+(SM-S936N, Android 16)에서 Camera2·CameraX 프리뷰, Gallery 일반·선택·상세, About·기기 정보·CLI·ZIP 대화상자를 확인했습니다. 실제 스크린샷 5개를 교체하고 7개를 추가했습니다.

실기기 리뷰에서 파일 공유·내보내기·삭제와 메일 전송은 실행하지 않았습니다. UI 검증은 카메라 성능이나 측정 회귀 검증을 대신하지 않습니다. 자세한 범위는 [Gallery·Lab UI 리뷰](../validation/gallery-lab-ui-20260930.md)와 [launch 진단 기록](../validation/launch-diagnostics.md)에 있습니다.
