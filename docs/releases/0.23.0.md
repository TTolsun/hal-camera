# HAL CAM 0.23.0

Live에서 셔터를 길게 눌러 연사하고 AEB로 노출 브래킷을 촬영할 수 있습니다. Dual 사진과 촬영·저장 데이터 관리 CLI를 확장했습니다. Live의 상시 설명을 줄이고 원래 버튼 배치를 복원했습니다.

## Installation

`HAL-Camera-0.23.0.apk`를 기존 앱 위에 설치합니다. 패키지는 `dev.halcamera`, versionCode는 `660`이며 Android 8.0 이상을 지원합니다. 기존 정식 인증서로 서명했으므로 앱을 삭제하지 않고 업데이트할 수 있습니다.

CLI 사용 지침은 함께 첨부한 `halcam-cli-0.23.0-SKILL.md`입니다. 이 릴리스 태그의 `skills/halcam-cli/SKILL.md`와 같은 파일이며, 기본 사용에는 PC의 ADB만 필요합니다. 선택 도구인 Python CLI 0.3.0 소스는 `halcamera-cli-0.3.0.zip`으로 제공합니다. 압축을 푼 폴더에서 `python -m pip install .`로 설치합니다. 파일 해시는 `SHA256SUMS.txt`에 있습니다.

## Changes

- Live 셔터를 누르고 있는 동안 연사합니다. AEB 제어에서 노출 브래킷을 촬영하고 가능한 경우 합성 HDR 이미지를 함께 저장합니다. 합성을 건너뛰면 이유를 표시하고 Gallery에서 브래킷 파일을 구분합니다.
- Dual에 메인 카메라 제어, 공통 줌과 두 카메라 사진 저장을 연결했습니다.
- 촬영·스트림·수동 제어·연사·AEB·Dual뿐 아니라 Gallery 파일, 결과 비교와 baseline 지정, 진단 ZIP, 보관 설정도 CLI로 조작할 수 있습니다. 삭제와 baseline 지정은 명시적 작업입니다.
- CLI의 시작 도움말을 줄이고 진행 상태, 저장 위치와 오류 후 다음 명령을 안내합니다. 취소·실패 후에도 저장된 파일을 회수할 수 있습니다.
- Live의 셔터 설명과 사진·영상 라벨을 제거하고 갤러리·셔터·줌 배치를 복원했습니다. Live와 Dual의 앱 문구를 영어로 통일했으며 촬영 진행·결과·오류는 필요한 시점에 표시합니다.
- 사용자 가이드의 작업별 탐색, 설명 그림과 전체 검색을 개선했습니다.

## Validation and limits

정식 APK에서 JVM 테스트 693개, Android lint와 release 빌드가 통과했습니다. APK의 패키지, 버전, minSdk 26, targetSdk 36, 비디버그 설정과 서명을 확인했습니다. 인증서 SHA-256은 기존 릴리스와 같은 `f2432413635645cc35e674e498e88ff518abb878065c21f17bb3c2128487b5c1`입니다.

Galaxy S25+ SM-S936N · Android 16/API 36에 정식 APK를 데이터 보존 업데이트로 설치했습니다. 앱의 정상 실행과 CLI hello의 `app_version: 0.23.0`, 확장 명령 목록을 확인했습니다. 촬영과 UI의 상세 검증은 아래 기능 PR 검증 기록에 있으며, 이번 버전 번호 변경 후 전체 CTS와 장시간 Benchmark를 다시 실행하지 않았습니다. 다른 기기·Android 버전, 모든 오류 조건과 접근성 설정을 실기기에서 검증한 것은 아닙니다.
