# HAL CAM 0.11.0

PC에 ADB만 설치되어 있어도 프리뷰, 사진 촬영, 동영상 녹화를 제어할 수 있습니다. Python 설치는 필요하지 않습니다.

## 설치

첨부된 `HAL-Camera-0.11.0.apk`를 기존 앱 위에 설치하세요. 앱 데이터와 실행 기록을 유지하려면 앱을 삭제하지 마세요.

| 항목 | 값 |
| --- | --- |
| 패키지 | `dev.halcamera` |
| 버전 | `0.11.0` · versionCode `113` |
| 지원 Android | Android 8.0 이상 · minSdk 26 / targetSdk 36 |
| 빌드 | 서명된 Release |
| 인증서 SHA-256 | `f2432413635645cc35e674e498e88ff518abb878065c21f17bb3c2128487b5c1` |

APK를 업데이트한 뒤, 포함된 CLI 스크립트를 기기에 다시 복사합니다.

```sh
adb shell "content read --uri content://dev.halcamera.cli/v1/shell > /data/local/tmp/halcam"
adb shell sh /data/local/tmp/halcam preview
adb shell sh /data/local/tmp/halcam capture
adb shell sh /data/local/tmp/halcam record start
adb shell sh /data/local/tmp/halcam record stop
adb shell sh /data/local/tmp/halcam preview stop
```

무선 디버깅으로 ADB에 연결한 뒤에도 같은 명령을 사용합니다. 녹음 없이 녹화하려면 `record start --no-audio`를 사용합니다.

## 변경 사항

- APK에 포함된 셸 CLI가 요청 ID 생성, 화면 열기, 완료 대기와 결과 파일 내보내기를 처리합니다. 출력된 `adb pull` 명령으로 결과를 가져올 수 있습니다.
- 프리뷰 시작·종료, 사진 촬영, 녹화 시작·종료를 지원합니다. 실제 녹화 시작을 확인하고, 취소·시간 초과가 발생한 요청에서도 저장된 파일을 복구할 수 있습니다.
- 카메라 목록, Probe, CTS 명령은 유지합니다. Benchmark는 CLI 지원 대상에서 제외하며 앱 화면에서 사용할 수 있습니다.
- 선택적으로 사용하는 Python CLI는 0.3.0으로 갱신했습니다. 기존 `benchmark` 명령은 제거되었습니다.

## 검증 범위

PR #120의 Android 빌드·단위 테스트·Lint, Windows·macOS·Linux CLI 테스트와 문서 CI가 통과했습니다. Galaxy S25+의 Android 16에서 USB 연결로 프리뷰, 사진, 오디오 포함·제외 녹화, 취소와 시간 초과 후 파일 복구를 확인했습니다. 이번 검증에서 무선 연결과 Android 8–15 실기기 검증은 완료하지 않았습니다.

자세한 사용법은 [CLI 가이드](../../guide/cli.md), 기능 검증 결과는 [실기기 검증 기록](../validation/cli-adb-only-20260920.md)을 참고하세요.
