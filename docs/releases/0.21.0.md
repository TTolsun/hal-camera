# HAL CAM 0.21.0

Live Streams에서 YUV 저장 포맷을 JPEG 또는 NV21로 선택합니다. 두 포맷 모두 촬영 메타데이터 JSON을 함께 저장합니다.

## Installation

`HAL-Camera-0.21.0.apk`를 기존 앱 위에 설치합니다. 패키지는 `dev.halcamera`, versionCode는 `630`이며 Android 8.0 이상을 지원합니다. 기존 정식 인증서로 서명하며 SHA256SUMS.txt로 해시를 제공합니다. 기존 앱 데이터는 업데이트 시 유지됩니다.

## Changes

- YUV Save Format의 JPEG는 기존 `_YUV.jpg`, NV21은 `_YUV.nv21`을 저장합니다. YUV 파일은 선택한 포맷 하나만 생성합니다.
- 사진 모드는 포맷과 관계없이 `_metadata.json`을 저장합니다. Camera2는 같은 센서 시각의 최종 촬영 결과를 기록합니다. 별도 카메라 JPEG 출력은 기존 선택을 따릅니다.
- NV21과 JSON은 Download/HALCamera, JPEG는 DCIM/HALCamera에 저장합니다. CLI도 실제 파일명과 MIME으로 결과를 제공합니다.
- Camera2를 다시 열 때 이전 카메라의 해제를 기다리고, 재시도 중 이전 세션의 콜백을 무시하도록 개선했습니다.

- 새 설치에서 ADB CLI를 기본 허용하고, 사용자가 저장한 꺼짐 설정은 유지합니다. 독립 배포용 CLI 스킬과 에이전트 안내도 정리했습니다.

## Validation

Galaxy S25+ SM-S936N·Android 16에서 Camera2 6가지 촬영 조합의 포맷 배타성, JSON의 센서 시각·노출, NV21 크기를 검증했습니다. UI 선택 유지와 CameraX의 JPEG·JSON 회수도 확인했습니다. JVM 657개 테스트, lint, 앱·instrumentation 빌드와 문서 검사를 통과했습니다.

NV21은 Camera2의 짝수 크기·프레임당 16 MiB 이하에서 지원합니다. CameraX는 일치하는 촬영 결과가 없으면 JSON에 unavailable로 표시합니다. 녹화 중 JPEG snapshot과 RAW/DNG는 이번 포맷 선택 범위에 포함하지 않습니다. Android 10 미만의 파일 저장 및 다른 기기 조합은 미검증입니다.

자세한 결과는 [YUV 저장 포맷 검증](../validation/original-yuv-20261008.md)을 확인하세요.
