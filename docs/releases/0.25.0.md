# HAL CAM 0.25.0

**PIP로 한 번 찍고, 갤러리에서 세 장을 비교해 보세요.** 합성 사진과 두 카메라 원본을 저장하며, Callback에는 카메라에서 받은 출력만 표시합니다.

## 직접 확인할 세 가지

1. 지원되는 PIP 카메라를 선택하고 JPEG를 켭니다. 셔터를 한 번 누른 뒤 합성·메인·보조 사진을 비교합니다. JPEG Off에서는 합성 한 장만 저장합니다.
2. Live의 크기 표시를 눌러 보조 Preview·Photo 크기를 바꿉니다. 꺼진 출력은 Live에서 사라지고, 활성 PIP 크기만 두 번째 줄에 표시됩니다.
3. Callback에서 Hold를 3초로 고르고 촬영합니다. Service PIP는 ID로 카메라를 전환합니다. PIP 합성 인코더는 HAL 출력이 아니므로 Recording 행을 만들지 않습니다.

## 달라진 점

- **PIP 선택:** 기기가 공개한 조합과 현재 스트림을 조회합니다. 확인된 지원 불가만 차단하고, 조회 불가인 후보는 선택할 수 있습니다. 제조사·칩셋·ID별 분기는 없습니다.
- **출력과 FPS:** PIP 보조 크기를 Live Streams에서 선택합니다. FPS는 한 항목으로 모으며 Photo의 녹화 설정은 비활성화합니다.
- **Callback:** 앱 JPEG 변환·합성·인코더 출력을 제외합니다. Camera2 Dual의 두 HAL Recording은 표시하고, 버퍼를 직접 관측하지 못하면 No callback입니다. ID·Hold 조작과 화면 전환도 정리했습니다.
- **문서와 코드:** 반복된 사용 설명을 연결로 통합하고 이전 검증 기록은 펼쳐서 봅니다. 요청 대상 추적·Live 표시 규칙·Dual 출력 ID를 공통 순수 Kotlin으로 관리합니다.

## 업데이트

`HAL-Camera-0.25.0.apk`를 기존 앱 위에 설치하세요. 패키지는 `dev.halcamera`, versionCode는 `671`입니다. 기존 앱을 삭제하지 마세요.

ADB 지침은 `halcam-cli-0.25.0-SKILL.md`이며 이 태그의 배포 스킬과 같습니다. 선택 도구인 Python CLI는 기존 0.3.0을 유지합니다. 첨부 파일 해시는 `SHA256SUMS.txt`에서 확인합니다.
