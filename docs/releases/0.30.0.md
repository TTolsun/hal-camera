# HAL CAM 0.30.0

**CLI에서 여러 독립 카메라의 프리뷰·사진·녹화를 실행하고, 카메라별 파일을 PC로 회수할 수 있습니다.** APK와 함께 배포하는 CLI 스킬을 갱신하세요. Python 클라이언트는 0.5.0입니다.

## 달라진 점

- `multi cameras`에서 조합과 크기를 고른 뒤 `multi preview|capture|record --cameras 1,0 [--engine Camera2|CameraX]`로 실행합니다. `--preview-sizes`와 `--photo-sizes`는 같은 카메라 순서의 목록입니다. 지원하지 않는 조합·크기를 자동 대체하지 않습니다.
- Multi 녹화는 기본으로 마이크 소리를 포함합니다. `--no-audio`이면 마이크 권한 없이 녹화하며, `record stop`으로 종료합니다. `live info`, `events`, `preview stop`도 현재 Multi 화면에 적용됩니다.
- 사진 일부가 실패해도 성공한 파일을 회수할 수 있습니다. 결과의 `cameras`에서 카메라별 저장 여부와 오류를 확인하세요. 회수 파일 이름에는 요청 ID와 카메라 ID가 들어갑니다.
- 녹화 준비 중 정지 요청을 보관하여 실제 시작 뒤 적용합니다. Dual·Multi에서 새 명령을 위해 Live로 돌아갈 때도 기존 카메라의 닫기 완료를 기다립니다.
- 최근 CLI 개선인 보관 요청 목록과 `halcam wait REQUEST_ID`, 공백이 있는 ADB 라벨의 인용 안내도 포함합니다.

## 업데이트와 한계

`HAL-Camera-0.30.0.apk`를 기존 앱 위에 설치하세요. 패키지는 `dev.halcamera`, versionCode는 `691`이며 기존 정식 서명을 사용합니다. 앱을 삭제하지 않아야 기존 기록과 설정을 유지할 수 있습니다.

Multi는 Android 11 이상이 필요하고 CameraX는 최대 두 카메라를 지원합니다. 녹화는 기존 Multi의 전체 묶음 저장 규칙을 따릅니다. 영상 하나라도 실패하면 묶음을 롤백합니다. Multi의 카메라별 수동 제어·측광, 녹화 중 사진, CLI 배치 지정은 이번 범위에 포함하지 않습니다. 센서 동시 촬영이나 영상·소리 동기의 새 보장은 없습니다.

사용법은 [CLI 가이드](https://ttolsun.github.io/hal-camera/cli.html), 검증 범위는 [0.30.0 검증 기록](../validation/release-0.30.0.md)을 확인하세요.
