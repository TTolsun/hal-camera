# HAL CAM 0.5.1

HAL CAM 0.5.1은 촬영 조작과 갤러리 정리를 개선한 버전입니다. 앱과 문서 사이트는 HAL-CAMERA-Editorial을 공통 디자인 기준으로 사용합니다.

## 0.5.0 이후 변경

- 촬영 화면 상단을 API 버튼 / Camera2·CameraX LIVE 상태 / Benchmark 메뉴 한 줄로 정리했습니다. API는 한 번 누를 때마다 전환하고, FPS·ISO·Exp·Lens·적용 줌을 유지합니다.
- 32dp 줌 원과 48dp 터치 영역을 사용합니다. 누르면 부드럽게 펼쳐지고, 마지막 조작 후 기본 3초가 지나면 선택한 배율로 접힙니다.
- 사진·동영상 직접 선택, 중앙 셔터와 최근 촬영물 썸네일을 제공합니다. 카메라 ID는 기존 목록에서 선택합니다.
- 갤러리 선택 모드에 전체 선택·전체 해제와 큰 선택 개수 표시를 추가했습니다. 사진·동영상 필터를 적용하면 그 항목만 전체 선택합니다.
- 갤러리 버튼 사이와 기능 행 사이의 여백을 늘렸습니다. 2,000개를 넘는 삭제는 여러 시스템 확인으로 나누어 처리합니다.
- 이전에 main에 병합된 `score-v1-draft` 내부 Camera Endpoint Score를 포함합니다. 검토된 Galaxy S25+ 후면 메인 endpoint의 적격 조건에서만 표시하며, 여러 기기의 성능 순위를 나타내는 공개 점수가 아닙니다. [점수 범위와 검증](../SCORING.md)을 참고하세요.

## 검증

Release·Debug 빌드, Release 단위 테스트 261개, lintRelease와 문서 파이프라인 검사를 통과했습니다. 문서 회귀 검사는 30개 통과, 모델 연결이 필요한 1개를 건너뛰었습니다.

Galaxy S25+ / Android 16에서 업데이트 설치와 버전·서명, 갤러리 22개 전체 선택, 개별 해제 시 21개 표시, 전체 해제, 사진 필터의 13개 선택, 삭제 확인·취소를 검증했습니다. 실제 사용자 파일은 삭제하지 않았습니다. 촬영 UI 작업 중 API 전환, 줌 선택·자동 접기·적용 배율 유지, 사진·동영상 모드와 저장·썸네일 갱신을 확인했습니다.

2,000개 초과 삭제의 연속 승인, Android 26–29, TalkBack과 전체 글꼴 배율은 실기기 검증에 포함하지 않았습니다. 이번 릴리스에서 새로운 전체 벤치마크 성능 측정은 수행하지 않았습니다.
