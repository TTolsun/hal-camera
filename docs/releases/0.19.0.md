# HAL CAM 0.19.0

Camera2 Live에서 손떨림 보정 모드를 선택하고, 실제 결과를 Live 상단에서 확인할 수 있습니다.

## Installation

`HAL-Camera-0.19.0.apk`를 기존 앱 위에 설치합니다. 패키지는 `dev.halcamera`, versionCode는 `628`이며 Android 8.0 이상을 지원합니다. 기존 정식 인증서로 서명하며 배포 파일 해시는 `SHA256SUMS.txt`에 제공합니다. 앱을 삭제하지 않고 업데이트하면 기존 저장 데이터를 유지합니다.

## Changes

- Camera2 Live Streams의 Mode에서 Auto·Off와 기기가 지원하는 OIS·EIS (Video)·EIS (Preview + Video)를 선택합니다. CameraX는 Auto를 유지하며 수동 보정은 Camera2에서 제공합니다.
- Live의 P·Y·J 크기 표시 옆에 실제 결과를 `EIS: V` 또는 `EIS: P, V`로 표시합니다. 확인할 수 없으면 `EIS: ?`, 정상적인 미적용 상태는 숨깁니다.
- 요청과 다른 결과가 1초 이상 관측되면 요청값과 실제값을 경고로 표시합니다. 이전 세션·촬영 단계의 값이나 오래된 결과는 적용 상태로 표시하지 않습니다.
- EIS 표시를 누르면 Live Streams가 열립니다. 기존 크기 표시와 같은 촬영·녹화·저장 중 진입 차단을 적용합니다.
- 보정 설명을 한 문장으로 줄이고 Last session result 영역을 삭제했습니다. 구성 실패 메시지와 이전 정상 구성 복원은 유지합니다.

## Validation

Galaxy S25+ (SM-S936N), Android 16/API 36에서 보정 모드 선택·실제 메타데이터, 프리뷰와 녹화 전환, 미적용 숨김, EIS 표시를 통한 설정 진입을 확인했습니다. JVM 테스트 633개와 Android lint가 통과했습니다. 상세 결과는 [실기기 검증 기록](../validation/live-stabilization-20261005.md)에 있습니다.

EIS 표시는 카메라 결과 메타데이터이며 흔들림 감소량의 실측값은 아닙니다. 불일치 경고는 JVM 테스트로 검증했으며 이번 실기기에서는 불일치 조합을 재현하지 않았습니다. 수동 OIS On은 검증 기기가 지원 목록에 제공하지 않아 검증하지 못했습니다. 모든 기기·해상도·FPS에서 동일하게 적용됨을 보장하지 않습니다.
