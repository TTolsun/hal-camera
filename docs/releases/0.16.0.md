# HAL CAM 0.16.0

Lab의 Live Streams에서 Camera2 해상도와 출력, 녹화 포맷을 선택할 수 있습니다. Lab과 설정 화면은 밝은 Apple 스타일로 통일했습니다.

## 설치

첨부된 `HAL-Camera-0.16.0.apk`를 기존 앱 위에 설치하세요. 패키지는 `dev.halcamera`, versionCode는 `592`이며 Android 8.0 이상을 지원합니다. 기존 정식 인증서로 서명하며 앱을 삭제하지 않고 업데이트하면 데이터를 유지합니다. 파일 해시는 `SHA256SUMS.txt`에서 확인할 수 있습니다.

## 변경 사항

- `Lab → Settings → Live Streams`에서 Preview·YUV·JPEG 크기와 프리뷰 FPS를 선택합니다. 해상도는 큰 순서로 표시하며 YUV·JPEG 출력을 각각 끌 수 있습니다.
- 녹화는 `Format → Resolution → Frame Rate` 순서로 선택합니다. 선택한 H264·HEVC 포맷에 맞는 지원 크기와 FPS를 표시합니다. 초기값에도 실제 해상도가 보입니다.
- 밝은 설정창, 둥근 목록, 영어 제목과 간결한 한국어 설명을 사용합니다. Lab 및 검사 화면 개편도 포함합니다.
- 요청한 출력 조합이 실패하면 이유를 표시하고 직전 정상 구성으로 복원할 수 있습니다. 명시한 해상도를 자동으로 낮추지 않습니다.
- 사진은 켜진 출력만 저장합니다. YUV 사진은 JPEG으로 변환하며 Benchmark와 CLI의 기존 기본 사진 쌍 계약은 유지합니다.

관련 변경: [PR #206](https://github.com/TTolsun/hal-camera/pull/206), [PR #207](https://github.com/TTolsun/hal-camera/pull/207).

## 검증 범위

Debug·Release 빌드, 각 JVM 테스트 599개, lint와 문서 검사 6단계가 통과했습니다. 기존 정식 인증서와 서명이 일치하며 Galaxy S25+ (SM-S936N, Android 16)에 업데이트 설치했습니다. 최초 설치 시각이 유지됨을 확인했습니다. 검증 기록은 [Live Streams](../validation/live-stream-settings-20260929.md)에 있습니다. 기기가 사용 중이므로 화면 조작·사진 촬영·녹화·출력 조합 실패 복구의 실기기 검증은 수행하지 않았습니다. 고속 녹화 세션은 제공하지 않습니다.
