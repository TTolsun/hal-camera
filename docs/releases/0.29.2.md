# HAL CAM 0.29.2

**Android lint 경고를 0개로 정리하고, 녹화 코드의 중복을 줄인 유지보수 릴리스입니다.** 촬영·녹화 동작은 0.29.1과 같습니다.

## 달라진 점

- lint 경고 132개를 처리했습니다. 77개는 코드를 고쳤고, 55개는 제품 결정(세로 고정, 번역 없음)과 도구 제약에 따라 근거를 적고 억제했습니다.
- Android 13 이상에서 테마 아이콘을 켜면 로봇 모양의 단색 아이콘이 표시됩니다.
- Multi V의 마이크 인코더와 영상 인코더가 같은 `EncoderTrack`으로 MP4에 기록합니다. 화면 회전 각도 변환은 `DisplayRotation` 한 곳에서 처리합니다.
- `activity-ktx` 1.13.0, `core-ktx` 1.18.0으로 올렸습니다.

## 업데이트와 한계

`HAL-Camera-0.29.2.apk`를 기존 앱 위에 설치하세요. 패키지는 `dev.halcamera`, versionCode는 `685`이며 기존 정식 서명을 사용합니다. 앱을 삭제하지 않아야 기존 기록과 설정을 유지할 수 있습니다.

대화면(sw600dp 이상) Android 16 기기에서는 세로 고정이 무시될 수 있습니다. 영상·소리 동기의 잔여 오차는 0.29.1과 같습니다.

판단 근거는 [lint 검토 기록](../validation/lint-audit-20261017.md), 기기 확인은 [0.29.2 검증 기록](../validation/release-0.29.2.md)을 참고하세요.
