# HAL CAM 0.15.0

Live에서 프레임별 콜백 도착 시각을 확인할 수 있으며, CameraX에서도 엔진을 바꾸지 않고 사진과 동영상을 저장합니다. 프리뷰 터치로 초점과 노출을 조절하고, 촬영 프레임은 자동으로 고정해 읽을 수 있습니다.

## 설치

첨부된 `HAL-Camera-0.15.0.apk`를 기존 앱 위에 설치하세요. 기존 정식 버전과 같은 인증서로 서명합니다. 앱을 삭제하지 않고 업데이트하면 앱 데이터와 실행 기록을 유지합니다.

## 변경 사항

- Live의 `Callback`은 Shutter·Metadata와 세션에 구성된 출력 스트림의 앱 수신 시각을 보여 줍니다. 숫자는 고정된 열에 정렬하고 시간축은 자동 조정합니다. JPEG 같은 비반복 출력은 기본 3초 동안 고정하며, `해제`로 실시간 갱신에 돌아갈 수 있습니다. 버튼은 한 줄로 표시됩니다. [PR #195](https://github.com/TTolsun/hal-camera/pull/195), [PR #197](https://github.com/TTolsun/hal-camera/pull/197)
- CameraX에서도 사진 쌍과 동영상 저장, Flash·AF·AE 잠금·EV, 터치 측광과 녹화 중 줌을 제공합니다. CameraX의 YUV 사진은 JPEG와 센서 시각이 가장 가까운 analysis 프레임이며, 같은 요청에서 두 버퍼를 받는 Camera2와 구분합니다. [PR #196](https://github.com/TTolsun/hal-camera/pull/196)
- 프리뷰를 짧게 터치하면 초점을 맞추고, 길게 누르면 해당 지점의 노출을 맞춘 뒤 잠급니다. 녹화 시작·종료로 세션이 바뀌면 노출을 다시 맞춘 뒤 잠금 상태를 복원합니다. [PR #189](https://github.com/TTolsun/hal-camera/pull/189), [PR #190](https://github.com/TTolsun/hal-camera/pull/190), [PR #192](https://github.com/TTolsun/hal-camera/pull/192)
- 촬영 제어와 줌 표시를 작게 정리하고, 엔진의 사진·녹화·관측 처리 코드를 분리했습니다. [PR #191](https://github.com/TTolsun/hal-camera/pull/191), [PR #193](https://github.com/TTolsun/hal-camera/pull/193), [PR #194](https://github.com/TTolsun/hal-camera/pull/194)
- 문서에 Engine·Callback 탭을 추가하고 중복 설명을 담당 페이지로 모았습니다. 기기 관찰과 문서 관리 절차는 Evidence에서 확인할 수 있습니다. [PR #198](https://github.com/TTolsun/hal-camera/pull/198), [PR #199](https://github.com/TTolsun/hal-camera/pull/199)

## 측정 범위

Callback은 앱이 받은 콜백과 버퍼의 시각을 표시하며 HAL 내부 완료 시각을 직접 측정하지 않습니다. Preview·Recording 버퍼 도착은 Camera2의 Android 13 이상 경로에서 관측합니다. CameraX에서는 두 출력의 도착 시각을 직접 관측하지 못해 `콜백 없음`으로 표시합니다.

기존 CameraX 검증은 Galaxy S25+의 후면 카메라 0에서 수행했습니다. 전면 카메라와 다른 기기에서 동일한 동작을 보장하는 결과는 아닙니다. 자세한 기록은 [Evidence](https://ttolsun.github.io/hal-camera/evidence.html#camerax-기기-관찰)에 있습니다.

## 릴리스 검증

- `assembleRelease`, `testReleaseUnitTest`, `lintRelease`를 통과했습니다. JVM 테스트 558개에 실패·오류·건너뛴 항목은 없습니다.
- APK 인증서가 기존 정식 버전과 같으며, 패키지 버전이 `0.15.0` / `543`이고 디버깅을 허용하지 않는 빌드임을 확인했습니다.
- 2026-09-27에 Galaxy S25+ (`SM-S936N`, Android 16)에 무선 ADB로 업데이트 설치했습니다. 앱을 삭제하지 않았으며 최초 설치 시각 `2026-09-16 02:33:27`이 유지됐습니다.
- 설치한 APK에서 Camera2·CameraX 프리뷰 전환, Callback 버튼의 한 줄 표시와 그래프 출력을 확인했습니다. Camera2의 Preview 수치와 CameraX의 `콜백 없음` 표시가 문서의 관측 범위와 일치했습니다.

이번 릴리스 설치 검증은 프리뷰와 Callback 화면을 대상으로 했습니다. 사진·녹화 시나리오의 기기 검증은 위 Evidence에 기록된 기능 PR의 결과를 참고하세요.
