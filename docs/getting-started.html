HAL CAMERA / User Guide

Install. Open. Check.

첫 사진을 저장하면, 카메라를 살펴볼 준비가 됩니다.

APK를 설치하고 Live에서 한 장을 찍어 보세요. 그다음 촬영 조건과 콜백을 차례로 살펴봅니다.

용어가 낯설면 Glossary에서 필요한 뜻만 확인하세요.

APK를 설치하세요

팀에서 지정한 검증 빌드가 있다면 그 APK를 사용합니다.

  1. Download에서 GitHub 릴리스를 열고 Assets의 APK를 받습니다.
  2. 기기에서 APK를 열어 설치합니다. 설치 허용을 요청하면 해당 파일을 연 앱에 허용합니다.
  3. HAL CAMERA를 열고 카메라 권한을 허용합니다.

소리를 함께 녹음하려면 마이크 권한도 허용합니다.

업데이트에서 서명 오류가 나면 기존 설치와 같은 서명의 APK를 받으세요.

앱을 삭제하면 내부 실행 기록이 사라집니다.

PC에서 설치하려면

기기의 USB 디버깅을 켜고 PC에 연결합니다. 기기에서 연결 요청을 승인한 뒤 다음 명령으로 설치합니다.

adb install -r "받은-파일.apk"

첫 화면을 확인하세요

  1. Live 상단에서 엔진을 고르고, 오른쪽 아래 카메라 버튼에서 카메라를 선택합니다.
  2. 프리뷰가 나오는지 확인합니다.
  3. 사진 모드에서 셔터를 누르고 저장 완료 안내를 확인합니다.
  4. 최근 썸네일을 눌러 저장된 사진을 확인합니다.

갤러리에서 방금 찍은 사진을 찾았다면 첫 촬영은 끝났습니다.

기본 사진은 카메라가 만든 JPEG 한 장입니다. 앱에서 YUV를 JPEG로 변환하려면 Live의 JPEG 출처 선택을 사용하세요.

다음에는 같은 장면에서 Callback을 켜고 Hold 3s를 선택한 뒤 한 장 더 찍어 보세요.

사진을 보는 데서 한 걸음 더 나아가, 이미지와 메타데이터가 도착하는 순서를 확인할 수 있습니다.

프리뷰·저장 성공만으로 HAL 적합성이 검증되는 것은 아닙니다.

확인할 작업을 고르세요

  • Live · 촬영 조건을 바꾸고 파일을 확인합니다.
  • Probe · 카메라가 공개한 지원 사양을 찾습니다.
  • CTS · 카메라 동작을 사전 점검합니다.
  • Benchmark · 같은 조건에서 반복 측정하고 결과를 비교합니다.
  • Callback · 같은 프레임의 콜백과 이미지 도착 순서를 읽습니다.
  • Automation · PC에서 반복 실행하고 결과를 받습니다.
  • Troubleshooting · 예상과 다른 결과의 원인을 좁힙니다.

다음 단계: Live에서 촬영 조건을 바꾸고 사진·동영상을 확인하세요.
