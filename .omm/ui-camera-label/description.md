화면에 카메라 이름을 적는 방법은 `CameraLabel` 한 곳에서 정합니다. 전체 형태는 `Camera · <키> (렌즈 · 방향 · 화각)`이고, 괄호에 넣을 값이 하나도 없으면 축약 형태인 `Camera · <키>`로 되돌립니다. 칸이 좁은 자리에서는 호출하는 화면이 `short()`를 골라 축약 형태를 씁니다.

렌즈 칸은 역할이 `MAIN`·`ULTRA_WIDE`·`TELE`일 때만 `Wide`·`UWide`·`Tele`로 채웁니다. 방향 칸은 HAL이 보고한 `LENS_FACING` 값을 따르며, 값이 없으면 역할이 `FRONT`인 카메라만 `Front`로 적습니다. 역할이 `EXTERNAL`이어도 보고값이 없으면 방향을 적지 않는데, 열거 과정이 `LENS_FACING`을 읽지 못한 카메라에도 `EXTERNAL`을 붙이기 때문입니다. 화각 칸은 렌즈 칸이 비었고 35mm 환산 초점 거리가 있을 때만 1mm 단위로 반올림해 채웁니다.
