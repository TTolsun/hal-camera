HistoryActivity는 RunIndex가 읽어 온 실행 목록을 두 줄짜리 행으로 그립니다. 첫 줄은 실행 시각과 뱃지 하나이고, 뱃지는 판정(▲ N degraded)이 있으면 판정을, 없으면 ResultPresenter.shortStatus의 짧은 적격성 표시(측정 무효·비교 불가·점수 제외)를 담습니다. 비교 가능하고 점수도 가능한 실행에는 뱃지가 붙지 않습니다. 둘째 줄은 촬영 시간과 카메라이며, 카메라 필터로 카메라 하나를 고른 상태에서는 모든 행이 같은 카메라이므로 촬영 시간만 적고 카메라는 접근성 설명에만 남깁니다. 빌드 이름은 입력한 실행에만 그 사이에 들어갑니다. run ID·profile·validity flag 원문은 행을 눌러 여는 결과 화면이 보여 주므로 목록에서는 생략합니다.

baseline인 실행은 BenchmarkIndex.baselinesFirst로 목록에서 떼어 `Baseline` 제목 아래 맨 위에 두고, 나머지는 `다른 실행 · N개` 제목 아래에 최신순으로 둡니다. baseline은 대개 그 카메라의 가장 오래된 실행이라 최신순 목록의 맨 끝에 놓였고, 회색 뱃지만으로는 찾기 어려웠기 때문입니다. 두 제목은 17sp 굵은 글씨이며 접근성 제목(accessibilityHeading)으로 지정합니다. baseline은 카메라마다 하나라 보통 1개이므로 개수는 2개 이상일 때만 `Baseline · N개`로 붙입니다. baseline 행에는 뱃지와 테두리를 두지 않습니다. 제목이 이미 baseline임을 알리고, 테두리 칩은 작업 메뉴 버튼과 같은 모양이라 버튼처럼 보였으며, 밝은 파란 테두리는 두 실행 비교에서 기준으로 고른 행을 뜻하기 때문입니다. 접근성 설명에는 ★ Baseline을 남깁니다. `더 보기` 페이지 나눔은 나머지 목록에만 적용합니다.

행 텍스트는 비례 글꼴로 그립니다. 행 사이에 자리를 맞출 열이 없고, 고정폭 글꼴의 넓은 자간 때문에 사실 줄이 작업 메뉴 버튼 뒤로 넘어가기 때문입니다. 접근성 설명에는 같은 정보를 한 줄로 이어 붙여 둡니다.

개수는 목록 위의 별도 줄 대신 묶음 제목에 적으며, baseline이 없으면 제목은 `실행 · N개` 하나입니다. 두 실행 비교와 목록 CSV 내보내기 버튼은 결과 화면처럼 한 줄에 나란히 두어 목록이 화면 위쪽에서 시작하게 합니다. 두 실행 비교의 결과는 BenchmarkResultCards.addCompare의 변화율 막대 카드로 그리며, 기준이 baseline이 아니면 판정하지 않으므로 모든 막대를 회색으로 그려 방향과 크기만 보여 줍니다. 목록은 두 실행 비교 버튼으로 선택을 시작하고, 각 행의 작업 메뉴에서 baseline 지정, 내보내기, 삭제에 접근합니다. 필터는 적격성과 카메라 두 가지입니다.
