BenchmarkRunner는 열기·닫기 반복과 추가 관측 세션을 분리합니다. 반복은 OPEN → CONFIGURE → FIRST_FRAME → CYCLE_CLOSE, 관측 세션은 WARMUP → OBSERVE → STILL → RECORD → CLOSE로 진행하며, 녹화 조건이 없는 profile은 RECORD를 건너뜁니다. 각 단계는 API 호출 직전에 마크를 남기고 현재 세션의 완료 신호를 기다리며, 시간 제한이 지나면 해당 단계를 실패로 닫습니다.

조기 종료 조건은 세 가지입니다. 연속 사이클 실패가 한도에 이르거나, 관측 세션이 첫 프레임에 실패하거나, 사용자가 abort를 누르는 경우입니다. 녹화 사이클의 실패는 여기에 포함되지 않습니다. 그 단계에 이를 때에는 실행·프리뷰·촬영 표본이 모두 확보된 뒤이므로, 사이클 하나만 실패로 기록하고 남은 사이클을 이어가거나 건너뛸 뿐 실행 전체를 무효로 만들지 않습니다.

녹화 단계는 timeout을 driver 호출보다 먼저 겁니다. 스트림 조합 거부처럼 동기로 답하는 driver가 이미 다음 단계로 넘어간 뒤에 timeout이 걸리는 일을 막기 위해서입니다.
