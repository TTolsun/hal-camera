Camera2Engine은 전용 HandlerThread에서 Camera2 요청과 세션을 관리하고 UI 상태는 메인 스레드로 전달합니다. Live에서는 preview·YUV·JPEG 크기를 픽셀 예산에 맞춰 선택합니다. BenchmarkActivity가 StreamSpec을 전달하면 정확한 profile 크기와 FPS 범위를 사용합니다.

사진 촬영과 플래시 precapture는 Camera2StillCapture(하위 요소 still-capture)가, Live 녹화는 Camera2LiveRecorder(하위 요소 live-recorder)가 맡습니다. 엔진은 두 클래스에 Host로 카메라·세션과 request 생성을 넘겨주고, 세션 구성·request 조립·Live 제어·줌·close를 직접 처리합니다. 프리뷰 버퍼를 늘어나지 않게 화면에 채우는 변환 행렬은 PreviewTransform.kt의 fitPreview가 만듭니다.

녹화 중에도 줌은 받습니다. 줌을 바꾸면 녹화 request를 같은 preview·인코더 target으로 다시 만들어 repeating request만 교체합니다. 줌 입력은 카메라 스레드에 한 번만 예약하므로, 빠르게 연속으로 조작하면 실행 시점의 마지막 배율 하나로 합쳐집니다. 녹화 세션이 구성 중이거나 종료 중이면 요청을 보내지 않고, 다음 세션이 구성될 때 현재 배율을 읽어 적용합니다. 정지와 겹쳐 닫힌 세션에 보낸 요청은 카메라 오류가 아니라 request_skipped 이벤트로 기록합니다.

프리뷰 터치(#168)의 순서는 Camera2TouchFocus가 맡고, 엔진은 meterAt에서 좌표를 받아 카메라 스레드로 넘기며 모든 LIVE request에 applyTouch로 영역을 넣습니다. 자세한 동작은 live-controls/touch-focus 요소에 있습니다. AF 잠금은 별도 key가 아니라 연속 AF 모드의 trigger 전이입니다. 잠글 때 AF_TRIGGER_START를 한 번의 capture로 보내고, 풀 때 CANCEL을 보냅니다. repeating request는 같은 AF 모드와 IDLE trigger를 유지하므로 잠금이 이어집니다. 녹화 시작·종료로 세션이 새로 만들어지면 잠금을 다시 겁니다. 제어 변경도 줌처럼 카메라 스레드에 한 번만 예약하므로, EV 다이얼을 빠르게 끌어도 실행 시점의 마지막 값 하나만 보냅니다. AE 잠금은 녹화 시작·정지나 카메라 재시작으로 세션을 새로 만들면 다시 겁니다(#184). CONTROL_AE_LOCK은 AE가 지금 가진 노출을 유지하라는 뜻이므로, 새 세션의 첫 request부터 잠그면 아직 수렴하지 않은 초기 노출로 잠깁니다(S25+ 어두운 장면에서 ISO 4274가 녹화 시작 직후 2990으로 바뀌었습니다). 그래서 AeRelock이 새 세션을 잠금 없이 시작하고, AE 상태가 CONVERGED·FLASH_REQUIRED로 결과 2개 연속 이어지거나 AE 상태가 없는 기기이면 repeating request를 잠금과 함께 다시 보냅니다. 결과 하나만 믿지 않는 이유는 HAL이 이전 세션의 CONVERGED를 새 세션의 첫 프레임에 그대로 적을 수 있기 때문입니다. 2초 안에 수렴하지 않으면 그 시점의 노출로 잠그고, 다시 잠그는 request를 보내지 못하면 안정 상태를 다시 기다립니다. 앱을 일시정지했다가 돌아오는 등 카메라를 다시 열 때는 화면이 저장해 둔 제어 값을 restore로 복원하므로, 복원된 AE 잠금도 같은 방식으로 수렴을 기다립니다. 기다리는 동안 촬영하면 AE가 풀려 있으므로 플래시 precapture를 생략하지 않습니다. 잠금 전 노출(노출 시간 × ISO)은 LOCKED 결과에서 기억하고, 다시 잠근 뒤 첫 LOCKED 결과와 비교해 1/3 EV를 넘게 다르면 화면에 차이를 알립니다. 녹화 FPS가 노출 시간을 프레임 길이 이하로 제한하므로 차이가 날 수 있습니다. 이전 노출 값을 AE OFF와 SENSOR_EXPOSURE_TIME·SENSOR_SENSITIVITY로 그대로 옮기는 방법은 쓰지 않았습니다. 수동 노출 경로(#172)가 필요하고, AE를 끄면 잠금 중 EV 변경이 동작하지 않기 때문입니다. AF 잠금도 새 세션에서 초점을 다시 잡으므로 이전 초점 거리를 옮기지 않습니다. Camera2는 AE 잠금 중에도 노출 보정을 적용하므로 잠금 중 EV 변경을 허용합니다. Galaxy S25+에서 AE 잠금 중 EV를 −0.7로 바꾸면 ISO가 6939에서 4274로 내려가는 것을 확인했습니다.

close는 active를 해제하고 세션과 기기를 닫습니다. finishClose에서 사진 대기와 녹화 정리, reader와 Surface 해제, closed 이벤트, 완료 콜백, 실행기 종료를 처리합니다. API 30 이상은 CONTROL_ZOOM_RATIO를, 이전 버전은 crop 영역을 사용합니다.
콜백 시간축용으로 capture_partial과 preview_presented를 관측하며, callback_streams 이벤트와 세션의 callbackStreams에 현재 출력 구성 및 관측 가능 여부를 기록합니다. 기존 capture_result·image_available의 의미는 유지합니다.
