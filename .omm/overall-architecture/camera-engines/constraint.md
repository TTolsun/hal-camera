- The stream sets differ between engines. Camera2 negotiates preview <= 1280x720, YUV <= 640x480 and JPEG <= 1920x1080 under its own pixel budget; CameraX lets the library choose and reads the result back. Numbers from the two engines are therefore only comparable after checking `negotiatedStreams` in the session map, which is why both engines record it.
- `close(done)` must fire `done` exactly once and only after the camera is released. Camera2 guards this with a `finished` flag inside `finishClose()`; CameraX guards it with a `finished` flag plus an `observeForever` observer that survives the Activity being stopped.
- Zoom below 1x requires API 30 (`CONTROL_ZOOM_RATIO`). Below that only the digital crop path exists, so ultra-wide cannot be reached by ratio.
- BenchmarkActivity passes a StreamSpec with 1920x1080 preview/YUV/JPEG and fps [30,30]. Camera2Engine validates those sizes; only the no-spec path uses the 1280x720 and 640x480 caps.
