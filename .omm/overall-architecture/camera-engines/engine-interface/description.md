CameraEngine 인터페이스는 start(), capture(), setZoom(ratio), close(done) 메서드를 선언하며, zoom 비율은 캡처 결과에서만 유효한 비율로 요청만 처리되고 close 콜백은 카메라를 반환함을 명시합니다. zoomRange() 함수는 API 30 이상에서 제어된 줌 비율 범위를 사용하며 그 아래에서는 디지털 줌 >= 1x 만 지원하므로 초광각 선택이 존재하지 않습니다. zoomPresets() 함수는 기기의 실제 보고에 따라 클립되며 최대 5 개의 항목으로 제한된 스톡 카메라 스타일의 버튼 행을 생성합니다. describeCamera() 함수는 하드웨어 레벨, 타임스탬프 소스, 렌즈 방향, 방향성, 기능, 물리적 ID, 줌 범위, 포맷별 출력 크기 및 목표 FPS 범위를 포함하여 세션을 해석 가능하게 스냅샷을 찍으며, 포맷 지원이 스트림 조합을 보장하지 않는다는 명시적 주석을 추가합니다.
