CameraEngine 인터페이스와 두 엔진 및 엔드포인트 리졸러가 공유하는 4 개 상위 레벨 헬퍼를 제공합니다. CameraEngine 은 start(), capture(), setZoom(ratio), close(done) 을 선언하며, zoom 인수는 요청된 비율만이며 실제 비율은 캡처 결과에서 알 수 있고, close 콜백은 카메라가 양도됨을 의미합니다. zoomRange(manager, id) 는 API 30 이상에서 CONTROL_ZOOM_RATIO_RANGE 를 읽으며 아래 버전에서는 1f..SCALER_AVAILABLE_MAX_DIGITAL_ZOOM 에Fallback 합니다. zoomPresets(range) 는 초점 거리 버튼 행을 구축하며, describeCamera(manager, id) 는 세션을 해석할 수 있는 특성을 스냅샷으로 저장합니다.
