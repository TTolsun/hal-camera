MultiCliBridge는 ConcurrentCameraActivity의 카메라 동작을 MultiController.Driver에 연결합니다. 명시된 advertised 조합과 카메라 순서·크기를 CliMultiOptions로 검사하고 기존 세션의 close(done) 이후에 구성합니다. MultiController는 multi.preview·multi.capture·multi.record와 현재 화면의 preview.stop·live.info·events를 처리합니다. 녹화의 record.stop은 시작 콜백 전이면 대기 후 정지합니다. 녹화에는 기본 마이크 오디오를 사용하며 audio=false는 권한 없이 무음으로 실행합니다. 카메라 ID별 저장 결과를 받아 요청 순서의 cameras 결과와 파일을 등록하고 일부 사진 실패도 성공 파일을 보존합니다. CLI 요청 중 화면의 세션 변경 조작을 막고 화면 이탈은 APP_NOT_FOREGROUND로 끝냅니다.
