CameraProbeActivity(PROBE)는 카메라를 열지 않고 CameraCharacteristics를 읽어 HAL이 공개한 사양을 카메라별 표로 보여 줍니다. camera/CameraProbeReader만 CameraManager를 알고, 공개 카메라 ID 전부와 논리 카메라 뒤의 물리 카메라를 섹션 단위로 읽어 camera/CameraProbe의 순수 Kotlin 모델(CameraProbeSnapshot)을 채웁니다. 섹션은 IDENTITY, CAPABILITIES, SENSOR, LENS, CONTROL, PROCESSING, REQUEST, SESSION KEYS(API 28 이상), MANDATORY STREAM COMBINATIONS(API 29 이상), 출력 형식별 STREAMS, HIGH SPEED VIDEO, REPROCESSING INPUTS, ALL CHARACTERISTICS 순서이며, enum 값의 이름은 CameraMetadata 상수에서 reflection으로 읽습니다. 읽지 못한 카메라나 섹션은 실패 목록에 남겨 내보낸 파일에도 무엇이 빠졌는지 적힙니다.

화면은 카메라 선택 목록, TXT·JSON 공유, 현재 카메라 복사, 섹션 접기·펼치기, 단어 필터를 제공합니다. LIVE 상단 도구 메뉴와 BenchmarkActivity에서 현재 카메라 ID를 초기값으로 받아 열리며, 카메라를 열지 않으므로 LIVE 카메라의 close(done)을 기다리지 않습니다. 이 화면은 측정하지 않으며 실제 동작은 BENCHMARK가 답합니다.
