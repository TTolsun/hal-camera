RecentMediaThumbnail이 MediaStore에서 HALCamera 앨범의 저장 완료 항목만 백그라운드로 조회하고, RecentMediaButton이 그 결과를 셔터 왼쪽의 원형 썸네일로 표시합니다. 조회는 파일 저장 직후와 화면 복귀 시에 일어나며, 항목이 없거나 읽기에 실패하면 썸네일 대신 갤러리 아이콘을 남깁니다.

촬영 화면을 벗어나면 변경 감시를 중단하고 뒤늦게 도착한 조회 결과는 반영하지 않습니다. 저장이 끝나지 않은 항목은 조회 대상에서 빠지므로, 셔터를 누른 직후의 빈 썸네일이 잘못된 사진으로 보이지 않습니다.

이 조회 경로는 Live 화면의 배치와 독립적입니다. MainActivity 하나만으로도 요소 스캔 입력이 6만 자 한도에 가깝기 때문에, 화면 배치와 별개의 주제인 최근 촬영물 조회를 이 하위 요소로 내렸습니다.
