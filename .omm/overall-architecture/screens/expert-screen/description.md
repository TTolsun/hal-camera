MainActivity는 LIVE 런처입니다. CameraEngine을 선택하고 카메라 수명주기·권한·incident 내보내기·CPU 샘플링과 관측 수치를 관리합니다. BenchmarkActivity로 벤치마크를 시작합니다. v0.2 HealthMonitor와 소비자용 Home 진입 경로는 제거되었습니다.

검은 프리뷰 배경과 하단의 원형 촬영 조작부는 삼성 카메라의 시각 구성을 참고합니다. 상단에는 현재 API를 표시하는 엔진 선택, 일시정지·재개 아이콘, 측정 상세를 둡니다. 하단의 촬영 행에는 왼쪽 갤러리 아이콘, 중앙 셔터, 오른쪽 카메라 선택을 둡니다. API·카메라 ID·모드·줌·필터·선택·MARK·벤치마크·측정 상세는 의미와 현재 값을 확인할 수 있도록 글씨를 유지합니다. 익숙한 동작에는 공통 IconButton의 24dp 아이콘과 48dp 이상의 터치 영역을 사용하며, 한국어 접근성 이름과 길게 누르기 설명을 제공합니다. 앱의 디자인 규칙은 docs/design/APP-UI.md에서 관리합니다.

프리뷰를 넓게 볼 수 있도록 LIVE의 측정 타일을 없애고 FPS·ISO·노출·초점·적용 줌만 2줄로 표시합니다. 프레임 간격 그래프와 PARTIAL·BUFFER 관측값은 측정 상세로 옮깁니다. 측정 상세 패널에는 닫기 아이콘을 둡니다. 줌과 셔터의 기존 하단 위치는 유지합니다.

엔진·카메라·촬영 모드, 벤치마크 카메라, RESULTS 필터는 누른 버튼에 붙는 드롭다운 목록을 사용합니다. 아래 공간이 부족하면 목록을 버튼 위에 표시합니다. 목록에는 현재 항목을 표시하며, 바깥을 누르거나 뒤로 가면 값을 유지하고 닫습니다. 화면을 나갈 때에도 목록을 닫습니다.

줌은 하단 프리뷰 영역에서 측정값 아래, 촬영 모드 위에 현재 배율을 표시하는 원형 버튼으로 둡니다. 원의 지름은 40dp이고 터치 영역은 48dp입니다. 버튼을 누르면 배율 목록이 가로로 펼쳐지며, 선택한 배율을 강조합니다. 마지막 조작 후 기본 3초가 지나면 선택한 버튼 하나로 다시 접힙니다. 접근성 설정에 따라 대기 시간을 늘리며, TalkBack 사용 중에는 선택하기 전까지 자동으로 접지 않고 배율을 선택하면 접습니다. 좁은 창에서는 가로로 스크롤해 모든 배율에 접근할 수 있습니다.

현재 사진·동영상 모드는 셔터 위에서 선택하며, 모드를 선택하는 것만으로 촬영하거나 녹화하지 않습니다. ShutterButton은 사진 모드에서 흰 원, 동영상 모드에서 흰 테두리와 빨간 원, 녹화 중에는 빨간 정지 사각형을 표시합니다. 녹화 중에는 모드 위치에 경과 시간을 표시합니다. 엔진·카메라·줌·모드 변경과 일시정지·갤러리·벤치마크는 비활성화합니다. 정지 셔터를 누르면 저장 중 상태를 표시하고, 녹화 종료 처리 동안 셔터를 비활성화해 중복 정지를 막습니다. 앨범 저장 완료는 별도 알림으로 표시합니다. 셔터 아래에는 MARK · ZIP 저장과 벤치마크를 글자로 표시합니다. CameraX에서 촬영·녹화를 요청하면 Camera2로 전환한 뒤 작업합니다.

GalleryActivity는 HALCamera 앨범만 조회해 화면 폭에 따라 3–6열의 정사각형 격자로 표시하며, 썸네일 간격은 2dp입니다. YUV·JPEG와 동영상 재생 시간 표시로 항목을 구별합니다. 전체·사진·동영상 필터는 버튼에 붙는 선택 목록을 사용합니다. 사진은 앱 내부에서 확대하고, 화면에 맞춘 크기에서는 좌우로 쓸어 넘기거나 이전·다음 아이콘으로 이동합니다. 돋보기의 +·−와 접근성 설명은 실제 확대 상태에 맞춰 바뀝니다. 동영상은 재생 아이콘을 눌러 시작합니다. 파일 상세 정보는 정보 아이콘을 펼쳤을 때 표시하며, 아이콘의 선택 상태도 함께 바뀝니다. 필터·스크롤 위치·열어 둔 항목을 저장하고 복원합니다. 선택 버튼이나 길게 누르기로 항목을 고른 뒤 공유·삭제 아이콘을 사용합니다. 공유에는 선택한 URI의 읽기 권한만 전달하고, 삭제는 확인을 거치며 Android 11 이상에서는 시스템 삭제 확인을 사용합니다.
