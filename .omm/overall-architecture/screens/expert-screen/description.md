MainActivity는 LIVE 런처입니다. CameraEngine을 선택하고 카메라 수명주기·권한·incident 내보내기·CPU 샘플링과 관측 수치를 관리합니다. BenchmarkActivity로 벤치마크를 시작합니다. v0.2 HealthMonitor와 소비자용 Home 진입 경로는 제거되었습니다.

엔진·카메라는 상단의 현재 값 버튼을 눌러 선택합니다. 촬영 모드, 벤치마크 카메라, RESULTS 필터와 함께 누른 버튼에 붙는 드롭다운 목록을 사용합니다. 아래 공간이 부족하면 목록을 버튼 위에 표시합니다. 목록에는 현재 항목을 표시하며, 바깥을 누르거나 뒤로 가면 값을 유지하고 닫습니다. 화면을 나갈 때에도 목록을 닫습니다. 일시정지·재개와 측정 상세도 상단에서 조작합니다.

줌은 하단 그래프와 측정값 사이에 현재 배율을 표시하는 원형 버튼으로 둡니다. 원의 지름은 40dp이고 터치 영역은 48dp입니다. 버튼을 누르면 배율 목록이 가로로 펼쳐지며, 선택한 배율을 강조합니다. 마지막 조작 후 기본 3초가 지나면 선택한 버튼 하나로 다시 접힙니다. 접근성 설정에 따라 대기 시간을 늘리며, TalkBack 사용 중에는 선택하기 전까지 자동으로 접지 않고 배율을 선택하면 접습니다. 좁은 창에서는 가로로 스크롤해 모든 배율에 접근할 수 있습니다.

MARK · ZIP 저장과 벤치마크를 주 작업으로 표시합니다. 보조 행에는 사진·동영상 모드 선택, 선택한 모드의 실행 버튼, 갤러리를 둡니다. 모드를 선택하는 것만으로 촬영하거나 녹화하지 않습니다. 녹화 중에는 실행 버튼에 중지와 경과 시간을 표시하고 엔진·카메라·줌·모드 변경을 비활성화합니다. CameraX에서 촬영·녹화를 요청하면 Camera2로 전환한 뒤 작업합니다. GalleryActivity는 HALCamera 앨범만 조회합니다.
