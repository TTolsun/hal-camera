MainActivity는 Live 런처입니다. CameraEngine을 선택하고 카메라 수명주기·권한·incident 내보내기·CPU 샘플링과 관측 수치를 관리합니다. BenchmarkActivity로 벤치마크를 시작합니다. v0.2 HealthMonitor와 소비자용 Home 진입 경로는 제거되었습니다.

검은 프리뷰 배경과 하단 촬영 조작부는 삼성 카메라를 참고합니다. 상단 한 줄에 현재 API 토글 버튼, 가운데 Live 상태, 오른쪽 `Benchmark` 메뉴를 표시합니다. 하단에는 핵심 측정값, 펼쳐지는 줌, 갤러리·셔터·카메라 선택 행, 사진·동영상 모드를 배치합니다. 아이콘은 24dp, 터치 영역은 48dp 이상이며 한국어 접근성 이름과 설명을 제공합니다. 디자인 규칙은 docs/design/APP-UI.md에서 관리합니다.

FPS·ISO·노출·초점·적용 줌을 촬영 화면에 2 줄로 표시합니다. 프레임 간격과 Partial·Buffer 그래프, Mark·일시정지는 진단 패널에서 제공합니다. 진단 패널의 제목은 `진단`이며 닫기 아이콘을 둡니다. Benchmark·Probe·CTS 는 상단 도구 메뉴에서 엽니다.

API 버튼을 누를 때마다 Camera2 와 CameraX 로 전환합니다. 사진·동영상은 각각의 버튼을 직접 누릅니다. 카메라 선택은 현재 ID 가 표시된 목록을 열며 전후면을 즉시 전환하지 않습니다. 벤치마크 카메라와 Results 필터도 목록을 유지합니다. 바깥 누르기·뒤로 가기·화면 이탈은 선택을 바꾸지 않고 목록을 닫습니다.

ExpandingZoomControl 이 줌의 펼침과 접힘을 처리합니다. 줌은 현재 배율만 표시하다가 누르면 지원 배율로 펼쳐집니다. 선택 후 3 초 동안 추가 조작이 없으면 선택한 배율을 유지한 채 접힙니다. 선택된 흰 원의 지름은 32dp이고 터치 영역은 48dp 입니다. 펼침은 260ms, 접힘은 220ms 동안 폭과 투명도·크기가 부드럽게 바뀝니다. 좁은 창에서는 가로 스크롤을 제공하고, 드래그 중에는 자동 접기를 미룹니다. 시스템 접근성 시간 제한을 반영하며 TalkBack 에서만 자동 접기 없이 선택을 기다린 뒤 접힙니다. 시스템 애니메이션 비활성화 설정도 따릅니다.

사진·동영상 모드는 셔터 아래에서 선택하며 모드 변경만으로 촬영하지 않습니다. ShutterButton 은 사진에서 흰 원, 동영상에서 흰 테두리·빨간 원, 녹화 중에는 정지 사각형을 표시합니다. 녹화 중 모드 위치에 경과 시간을 표시하고 API·카메라·줌·모드·일시정지·갤러리·벤치마크를 비활성화합니다. 정지 처리 동안 셔터를 비활성화합니다. CameraX 에서 촬영·녹화를 요청하면 Camera2 로 전환한 뒤 작업합니다. RecentMediaThumbnail 이 저장 완료된 앨범 항목을 백그라운드에서 읽어 RecentMediaButton 에 원형 썸네일로 표시하며 화면 이탈 후의 늦은 결과는 버립니다.
