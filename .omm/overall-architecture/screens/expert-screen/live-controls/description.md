LiveControlBar는 Live 상단의 카메라 제어 줄입니다. 평소에는 상태 줄 아래 가운데에 아래 화살표가 든 알약 하나만 보이고, 누르면 플래시·AF·AE·EV 원형 버튼 네 개가 펼쳐집니다. 다시 누르거나 카메라·API를 바꾸면 접힙니다. 접힌 알약에는 켜 둔 제어(`Torch`, `AF lock`, `AE lock`, `EV +0.7` 등)를 이어서 표시하므로, 숨겨 둔 잠금이나 EV가 사용자 모르게 사진을 바꾸지 않습니다.

버튼은 지름 40dp의 원이고 터치 영역은 칸 전체입니다. 꺼진 버튼은 줌 레일과 같은 어두운 유리색, 켜진 버튼은 흰 원에 어두운 글리프로 표시합니다. AF·AE 잠금이 걸리면 글자 아래에 작은 자물쇠를 그립니다. 플래시 버튼을 누르면 같은 자리가 Off·Auto·On·Torch 아이콘과 이름으로 바뀌고, 하나를 고르면 원래 줄로 돌아옵니다. 동영상 모드에서는 Off·Torch만 보입니다. EV 버튼은 버튼 줄 아래에 EvRuler를 엽니다. 플래시 선택지는 하나를 고르거나 알약을 누를 때만 접힙니다. 시간이 지나 저절로 접히면 선택지를 누르려던 손가락 아래에 AE 버튼이 나타나 잘못 눌리기 때문입니다. 다이얼은 마지막 조작 4초 뒤에 접히며, 다이얼이 있던 자리에는 다른 버튼이 없으므로 같은 문제가 생기지 않습니다.

EvRuler는 가운데 고정 표시 아래로 눈금이 움직이는 노출 보정 다이얼입니다. 기기의 EV 단계마다 짧은 눈금을, 정수 EV에 가장 가까운 단계에 긴 눈금과 숫자를 그립니다. 끄는 동안 지나는 단계마다 바로 요청을 보내고 햅틱을 주며, 손을 떼면 가까운 단계에 맞춥니다. 두 번 탭하면 0으로 돌아갑니다. TalkBack에서는 조절 가능한 컨트롤로 노출되어 앞뒤 스크롤 동작이 한 단계씩 움직입니다. 목록 대신 다이얼을 쓰는 이유는 단계가 기기마다 다르기 때문입니다. 1/3 EV 기기는 13개, Galaxy S25+처럼 0.1 EV 기기는 41개 값이 나옵니다.

지원하지 않는 제어는 숨기지 않고 흐리게 표시하며, 누르면 이유를 알립니다. 전면 카메라에 플래시가 없다는 사실도 개발자가 확인할 대상이기 때문입니다. CameraX에서 버튼을 누르면 Camera2로 전환한다고 알리고 엔진을 바꾼 뒤, Camera2 세션이 준비되면 버튼 줄을 다시 펼치고 누른 동작을 이어서 실행합니다. 따라서 한 번만 누르면 제어가 켜집니다. 녹화 중에는 엔진을 바꿀 수 없으므로 아무 일도 하지 않습니다. 버튼은 요청값만 보여 주고, 실제 적용값은 MainActivity가 capture result에서 읽어 프리뷰 아래 수치 줄에 표시합니다. 그 줄에 쓰는 짧은 상태 이름(stateLine, appliedExtras)도 이 클래스가 만듭니다.
