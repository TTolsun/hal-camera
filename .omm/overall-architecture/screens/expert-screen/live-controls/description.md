LiveControlBar는 Live 상단의 카메라 제어 줄입니다. 상단 중앙에는 글씨 없이 아래 화살표만 표시하며, 누르면 플래시·AF·AE·EV 원형 버튼 네 개가 펼쳐집니다. 펼친 동안에는 위 화살표로 바뀝니다. 다시 누르거나 카메라·API를 바꾸면 접힙니다. 켜 둔 제어는 펼친 버튼의 선택 상태와 화살표의 접근성 이름·길게 누르기 설명에서 확인합니다.

LiveIndicator는 API 버튼 아래에 5dp 원과 10sp Live 글씨를 표시합니다. MainActivity가 프리뷰 프레임 수신 여부를 전달하면 원과 글씨가 함께 빨간색으로 천천히 깜빡이며, 정지 상태에서는 회색으로 고정됩니다. 시스템 애니메이션이 꺼져 있으면 동작 중에도 빨간색을 고정합니다. 화면이 보이지 않거나 뷰가 분리되면 애니메이션을 취소합니다. 녹화 상태와는 별개의 프리뷰 표시이며 녹화에는 기존 REC 표시를 사용합니다.

버튼은 지름 40dp의 원이고 터치 영역은 칸 전체입니다. 펼치기 화살표과 제어 버튼은 48dp 이상의 터치 영역을 확보합니다. 버튼 아래에 상시 설명을 붙이지 않으며, 접근성 이름과 길게 누르기 설명으로 동작을 확인합니다. 꺼진 버튼은 줌 레일과 같은 어두운 유리색, 켜진 버튼은 흰 원에 어두운 글리프로 표시합니다. AF·AE 잠금이 걸리면 글자 아래에 작은 자물쇠를 그립니다. 플래시 버튼을 누르면 같은 자리가 Off·Auto·On·Torch 아이콘으로 바뀌고, 하나를 고르면 원래 줄로 돌아옵니다. 선택지의 원은 원래 버튼과 같은 중심선에 두고 이름만 그 아래에 붙이므로, 줄이 바뀌어도 원의 위치는 움직이지 않습니다. 동영상 모드에서는 Off·Torch만 보입니다. EV 버튼은 버튼 줄 아래에 EvRuler를 엽니다. 플래시 선택지는 하나를 고르거나 화살표를 누를 때만 접힙니다. 시간이 지나 저절로 접히면 선택지를 누르려던 손가락 아래에 AE 버튼이 나타나 잘못 눌리기 때문입니다. 다이얼은 손을 뗀 뒤 기본 4초 후에 접힙니다. 시스템의 접근성 시간 연장 설정을 따르며 TalkBack의 터치 탐색 중에는 자동으로 접지 않습니다. 다이얼이 있던 자리에는 다른 버튼이 없으므로 같은 문제가 생기지 않습니다.

EvRuler는 가운데 고정 표시 아래로 눈금이 움직이는 노출 보정 다이얼입니다. 기기의 EV 단계마다 짧은 눈금을, 정수 EV에 가장 가까운 단계에 긴 눈금과 숫자를 그립니다. 끄는 동안 지나는 단계마다 바로 요청을 보내고 햅틱을 주며, 손을 떼면 가까운 단계에 맞춥니다. 두 번 탭하면 0으로 돌아갑니다. 다이얼 양옆의 `− / + / 0` 버튼으로 한 단계씩 조절하거나 0으로 되돌릴 수 있습니다. 다이얼과 버튼은 높이 64dp의 한 줄을 공유합니다. 키보드의 좌우 키도 한 단계씩 조절하며 Home 키는 0으로 되돌립니다. TalkBack에서는 조절 가능한 컨트롤로 노출되어 앞뒤 스크롤 동작이 한 단계씩 움직입니다. 목록 대신 다이얼을 쓰는 이유는 단계가 기기마다 다르기 때문입니다. 1/3 EV 기기는 13개, Galaxy S25+처럼 0.1 EV 기기는 41개 값이 나옵니다.

지원하지 않는 제어는 숨기지 않고 흐리게 표시하며, 누르면 이유를 알립니다. 전면 카메라에 플래시가 없다는 사실도 개발자가 확인할 대상이기 때문입니다. CameraX에서 버튼을 누르면 Camera2로 전환한다고 알리고 엔진을 바꾼 뒤, Camera2 세션이 준비되면 버튼 줄을 다시 펼치고 누른 동작을 이어서 실행합니다. 따라서 한 번만 누르면 제어가 켜집니다. CameraX 녹화 중에는 엔진을 바꿀 수 없으므로 먼저 녹화를 마치라는 안내를 표시합니다. 버튼은 요청값만 보여 주고, 실제 적용값은 MainActivity가 capture result에서 읽어 프리뷰 아래 수치 줄에 표시합니다. 그 줄에 쓰는 짧은 상태 이름(aeState, afState, flashState, evApplied)도 이 클래스가 만듭니다.

Live 제어(LiveControls)는 EV, AE 잠금, AF 잠금, 플래시 모드를 담는 순수 Kotlin 값입니다. LiveControlSupport가 CameraCharacteristics에서 EV 범위·단위, AE_LOCK 지원, 연속 AF와 가변 초점 여부, 플래시 유무와 플래시 AE 모드를 읽고, coerce가 지원하지 않는 값을 끕니다. 동영상 모드에서는 스틸에서만 발광하는 Auto·On을 빼고 Off·Torch만 허용합니다. applyLiveControls는 preview·still·녹화 request에 같은 AE 모드, EV, AE 잠금, 토치를 넣으므로 request가 바뀌어도 잠금이나 EV가 빠지지 않습니다. 벤치마크(spec이 있는 경우)에는 적용하지 않아 profile 측정 계약을 바꾸지 않습니다.
