LiveBurst는 연사와 AEB 브라케팅의 시작·중단·완료를 관리합니다. BurstRun은 앞 장의 저장이 끝나고 카메라가 준비된 뒤 다음 장을 요청하는 순수 상태 기계입니다. 연사는 셔터를 누르고 있는 동안 최대 50장을 찍고 손을 떼면 멈춥니다. AEB는 한 번 눌러 세 장을 찍으며 손을 떼어도 계속합니다. 두 동작 모두 촬영 중에는 셔터가 흰 정지 사각형으로 바뀌고, 누르면 다음 장부터 중단합니다. 이미 요청한 장은 저장을 마칩니다. TalkBack의 Start burst 동작으로 시작한 연사는 셔터의 Stop burst로 멈춥니다.

촬영 중 controlsLocked가 켜져 EV·플래시·수동 제어·줌·터치 측광과 카메라·엔진·모드 변경을 막습니다. AEB는 각 장의 EV를 적용하고 500ms 기다리며, 완료나 중단 후 같은 엔진에 시작 당시 설정을 복원합니다. CaptureFeedback은 셔터 위에 AEB 0/3, Burst · 2, Stopping…, HDR…과 같은 상태를 표시합니다. 완료 결과는 기본 5초 동안 표시하고 접근성 시간 연장 설정을 따릅니다. 진행 상태가 결과보다 우선하며 AEB가 켜진 대기 상태에는 AEB만 표시합니다.

BracketFusion은 세 원본의 JPEG를 읽어 ExposureFusion으로 합성합니다. 합성 중에는 다음 AEB를 중복 접수하지 않으며 카메라 설정과 일반 촬영은 다시 사용할 수 있습니다. 저장 실패나 JPEG 출력이 없는 경우에는 HDR 생략 이유를 결과에 표시합니다. Activity가 소멸하면 LiveBurst.dispose가 이후 UI 콜백을 차단하고 executor를 shutdown합니다. 이미 접수한 합성·저장은 완료한 뒤 worker를 종료합니다. 원본 JPEG와 합성 파일은 기존 저장 경로를 유지합니다.
