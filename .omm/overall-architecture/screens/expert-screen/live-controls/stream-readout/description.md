LiveStreamReadout은 활성 출력 선택과 화면·접근성 문구를 만드는 순수 Kotlin 규칙입니다. LiveIndicator는 결과를 뷰에 반영하고 프리뷰 heartbeat를 표시합니다. 꺼진 출력·빈 크기·합성 파일 크기는 숨기고 YUV JPEG의 원본 크기는 유지합니다.

LiveIndicator는 API 버튼 아래에 5dp 원과 10sp Live 글씨를 표시합니다. MainActivity가 프리뷰 프레임 수신 여부를 전달하면 원과 글씨가 함께 빨간색으로 천천히 깜빡이며, 정지 상태에서는 회색으로 고정됩니다. 시스템 애니메이션이 꺼져 있으면 동작 중에도 빨간색을 고정합니다. 화면이 보이지 않거나 뷰가 분리되면 애니메이션을 취소합니다. 녹화 상태와는 별개의 프리뷰 표시이며 녹화에는 기존 REC 표시를 사용합니다.
