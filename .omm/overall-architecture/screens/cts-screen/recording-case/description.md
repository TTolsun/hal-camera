cts/recording/BasicRecordingRules가 CTS RecordingTest#testBasicRecording의 판정 규칙·상수·assertion 문구를 순수 Kotlin으로 옮긴 것입니다. 프리뷰 상한(1080p 또는 창 크기)·영상 크기 상한·CamcorderProfile 계획(없으면 SKIP, LEGACY 예외, 크기·FPS 미지원이면 FAIL)·24 FPS 하한·validateRecording(파일·트랙·크기·길이 오차 20 %·프레임 드롭률)을 담고, validate의 프레임 드롭 허용률은 인자로 받아 VideoSnapshot이 자기 값을 넘길 수 있습니다. 커스텀 케이스 목록에 기본 녹화 케이스는 없습니다. RecordingTest#testBasicRecording은 CTS 원문 경로(vendored-cases)로만 실행하며, 이 규칙은 SwitchingRunner와 VideoSnapshotRunner가 녹화 판정에 공유합니다.

녹화 호출은 cts/recording/CamcorderRecording에 있습니다. prepareRecording → 프리뷰·녹화 Surface의 TEMPLATE_RECORD 세션 → 첫 capture start → MediaRecorder.start → body → 세션 close 대기 → recorder.stop 순서이며, body는 Live(세션·반복 요청·두 Surface)를 받아 잠들거나 같은 세션에 정지 영상을 요청할 수 있고, extraOutputs로 JPEG 리더 같은 출력을 세션에 더할 수 있습니다. cts/recording/CamcorderProfiles가 숫자 카메라 ID의 프로파일을 CTS 순서로 읽고, cts/recording/RecordingReader가 MediaExtractor로 비디오 트랙의 크기·길이·샘플 시각을 읽습니다. 녹화 파일은 cacheDir의 test_video.mp4에 쓰고 판정 뒤 삭제합니다. 케이스를 추가하면 규칙은 순수 Kotlin에 두고 JVM 테스트(app/src/test/java/dev/halcamera/cts/)를 함께 씁니다.
