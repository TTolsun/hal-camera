CTS는 Live 상단 도구 메뉴에서 Live 카메라의 close(done)을 받은 뒤 cts/vendored/VendoredCtsListActivity로 바로 열립니다. VendoredCts.MIN_SDK(34) 아래 기기에서는 MainActivity가 안내 toast만 띄우고 화면을 열지 않습니다. 커스텀으로 옮겨 적은 케이스는 없고, 목록의 모든 항목이 :ctsvendor 모듈에 가져온 AOSP 테스트 메서드입니다.

VendoredCatalog.classes에 등록된 클래스(RecordingTest, StillCaptureTest, BurstCaptureTest)의 @Test 메서드를 reflection으로 나열하므로, 클래스를 하나 더 가져오면 그 메서드 전부가 체크리스트와 CLI cts.cases에 함께 나타납니다. 항목 키는 vendored:<class>#<method>이고 suite/SuitePlan이 선택 순서와 예상 시간을, suite/SuiteReport가 보고서를 만듭니다. 체크한 항목은 suite/CtsSuiteRunActivity가 차례로 실행하고, 행의 ›는 vendored/VendoredCaseActivity로 메서드 하나만 실행합니다.
