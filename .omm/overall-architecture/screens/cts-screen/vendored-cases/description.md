VendoredCtsListActivity는 :ctsvendor 모듈의 VendoredCatalog가 reflection 으로 나열한 @Test 메서드를 클래스별 그룹으로 보여 주는 체크리스트(cts/suite/CtsChecklistActivity 상속)입니다. 체크한 메서드는 하단 바의 실행으로 cts/suite/CtsSuiteRunActivity 가 차례로 실행하고, 행의 › 버튼을 누르면 cts/vendored/VendoredCaseActivity 가 EXTRA_TEST_ID 로 메서드 하나를 호스트합니다. 이 Activity 는 가져온 Camera2SurfaceViewCtsActivity 를 상속해 테스트의 ActivityTestRule 이 돌려받는 인스턴스가 되며, 가져온 레이아웃의 SurfaceView 를 앱 화면의 180dp 프레임으로 옮겨 붙이고 surfaceChanged 마다 버퍼 비율대로 letterbox 합니다. 실행은 카메라·마이크 권한을 확인한 뒤 VendoredRun 을 cts-vendored 스레드에서 돌리고, 상태 줄에는 JUnit 이 알려 준 메서드 이름과 경과 시간만 갱신됩니다. 테스트 본문이 카메라 전부를 스스로 순회하므로 진행 단계는 알 수 없습니다.

VendoredRun 은 Request.aClass(...).filterWith(메서드 필터)로 JUnit runner 를 만들고 RunNotifier 의 testStarted·testFailure·testAssumptionFailure 로 결과를 모아 VendoredResult(PASS·FAIL·SKIP, 소요 시간, 실패 문구, 중단 여부)를 냅니다. 중단은 RunNotifier.pleaseStop 과 함께 VendoredCts.closeRunningCamera 로 실행 중인 테스트의 mCamera 를 닫아 본문을 실패시키는 방식입니다. JUnit 이 실행 중인 본문을 멈출 수단이 없기 때문입니다. cts/vendored/VendoredReportPresenter 가 머리글과 복사·공유 텍스트를 만들며, 중단된 실행은 FAIL 대신 중단됨을 앞세웁니다. VendoredCts.MIN_SDK(34) 아래 기기에서는 CtsEntryActivity 가 이 경로를 비활성화합니다. RecordingTest#testBasicRecording 은 이 경로로만 실행되며, 커스텀 케이스에는 없습니다.
