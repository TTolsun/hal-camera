cts/CameraCaseRunner는 모든 케이스 러너의 기반 클래스입니다. 공개 카메라 ID를 순회해 카메라마다 runCamera를 부르고(카메라를 섞어 쓰는 케이스는 runCameras를 재정의), 단계가 결정되면 step으로 Listener.onStep을 보내며, 마지막에 CaseReport 하나로 끝냅니다. cancel은 카메라 사이와 sleepUnlessCancelled 대기에서 확인하고, 취소된 실행도 완료된 단계까지 담아 cancelled=true로 보고합니다. runCamera를 벗어난 예외는 그 카메라의 FAIL 행이 되고, 그 밖의 예외는 "-" 행이 되어 보고서가 비지 않습니다. openCycle은 열기 → SurfaceView 프리뷰 세션 → TEMPLATE_PREVIEW 첫 결과 → 닫기 한 번을 수행해 OpenCycle(각 구간 ms·닫기 시간 준수·오류)과 첫 결과를 돌려주며, FastOnOff·Switching·AllSizeOnOff가 같은 패스를 씁니다.

cts/Camera2Ops는 케이스가 공유하는 Camera2 호출입니다. 러너가 소유한 HandlerThread 하나에서 open·configure(SessionConfiguration, API 28 미만은 구식 createCaptureSession)·startRepeatingAndAwaitFirstFrame·captureStill을 제공하고, 모든 대기는 CTS CameraTestUtils와 같은 3초 예산(open·configure·첫 결과·이미지·close, surfaceChanged는 1초)이며 초과하면 CTS 문구의 IllegalStateException을 던집니다. open은 3초 뒤에 도착한 장치를 누수 없이 닫고, OpenedCamera는 onError·onDisconnected를 error로 보관해 러너가 장치 이상을 FAIL로 기록하게 합니다. cts/CameraFacts는 CameraCharacteristics에서 컬러 출력·LEGACY·EXTERNAL·타임스탬프 소스·SurfaceHolder 크기(전체와 1080p 상한)·JPEG 크기와 testBasicRecording의 CameraInfo를 읽고, cts/JpegReader는 CTS SimpleImageReaderListener처럼 JPEG 이미지를 큐에 모아 시간 제한으로 꺼내며 BitmapFactory 경계 디코딩으로 ImageInfo를 만듭니다. cts/OpenCycle은 한 패스의 순수 기록으로 요약 줄과 실패 사유를 만듭니다.
