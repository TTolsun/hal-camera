GalleryActivity는 LIVE 셔터 행의 썸네일에서 여는 앨범 화면입니다. DCIM/HALCamera의 저장 완료 항목만 MediaStore에서 조회해 검은 배경의 정사각형 격자(화면 폭에 따라 3–6열, 간격 2dp)로 표시하고, 사진에는 YUV·JPEG 표시를, 동영상에는 재생 시간을 붙입니다. 전체·사진·동영상 필터는 현재 값 버튼에 붙는 선택 목록입니다.

항목을 누르면 앱 안의 상세 화면을 엽니다. ui/GalleryImageView가 두 손가락·두 번 누르기·돋보기 아이콘 확대와 이동을 처리하고, 화면에 맞춘 크기에서는 좌우로 쓸어 넘기며 이전·다음 아이콘도 제공합니다. 동영상은 재생 아이콘으로 시작하고, 파일명·크기·해상도 등은 정보 아이콘을 펼쳤을 때 표시합니다. 선택 버튼이나 길게 누르기로 여러 항목을 고르고 공유·삭제 아이콘으로 처리하며, 삭제는 Android 11 이상에서 MediaStore.createDeleteRequest()의 시스템 확인을 거칩니다. 필터·스크롤 위치·열어 둔 항목은 화면 복귀와 재생성 시 복원합니다. 저장 경로와 앨범 갱신은 camera/MediaLibrary와 camera/RecentMediaThumbnail이 담당합니다.
