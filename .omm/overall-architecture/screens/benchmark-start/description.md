StartCardPresenter와 ProgressPresenter는 벤치마크 시작 카드(8.2)와 진행 화면(8.3)의 순수 화면 모델입니다. StartCardPresenter는 preflight 결과·발열·절전 상태에서 시작 가능 여부와 notices·blockedReason을 결정하며, 라벨은 영어·설명 문장은 한국어입니다(`10× open · 10초 관측 · 사진 10장`, `약 45초 · 화면 켠 채 · 밝은 피사체에 고정`). 제목은 측정 조건과 launch mode(`1080p30 · warm reopen`)이며, 카메라는 카드 아래 선택 버튼이 표시하므로 넣지 않습니다. SEVERE 발열이면 START를 막고, 화면이 5초마다 preflight를 다시 실행해 식으면 START가 돌아옵니다. ProgressPresenter는 여섯 단계를 시간 가중치로 환산해 진행 막대와 상태 줄을 만듭니다. 두 presenter 모두 Android 의존성 없이 JVM 테스트로 검증합니다.
