`app/src/main/java/dev/halcamera/metrics/MetricModel.kt`는 Doctor 시절 모델 중 M3 이후에도 남은 세 선언을 담습니다. `UnknownReason`은 값이 없는 이유(NOT_MEASURABLE, NOT_RUN, INSUFFICIENT_SAMPLES, NO_BASELINE, UNSUPPORTED, CADENCE_CHANGED, CONDITION_MISMATCH)를, `MetricSample`은 비교 전의 측정값 하나(value, p95, n, hardFailure, unknownReason, expectedMs, fixedCadence, timeout)를 나타냅니다. `jsonName`은 enum 이름을 소문자로 직렬화합니다. PASS / WARN / FAIL 같은 판정 어휘는 이 파일에 없습니다.
