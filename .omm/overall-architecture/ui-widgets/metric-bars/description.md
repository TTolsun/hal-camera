MetricBars.kt의 MeterView는 벤치마크 결과 화면과 실행 기록의 두 실행 비교가 함께 쓰는 막대 뷰입니다. 0 기준선 변화율 막대를 그리던 DeltaBarView는 비교 그림을 막대와 눈금 하나로 합치면서 없앴습니다. MeterView는 이번 run 값을 가로 막대로, baseline 값을 같은 스케일의 눈금으로 그려 저하 여부를 숫자 없이 보여 줍니다(저하면 statusFail, 아니면 primaryOnDark). 눈금은 흰색(onDark) 2dp 굵기로 그립니다. 회색 3px 눈금은 어두운 트랙 위에서, 특히 범례에서 거의 보이지 않았기 때문입니다. 기준 값이 트랙을 넘으면(baseBeyond) 눈금 대신 트랙 끝에 작은 삼각형을 그립니다. Look 토큰 색만 사용하고 onDraw에서 직접 그립니다. 막대의 분율 계산은 ResultPresenter.metricBars가 담당하므로 뷰에는 수치 로직이 없습니다.
