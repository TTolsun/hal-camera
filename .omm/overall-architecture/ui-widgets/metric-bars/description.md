MetricBars.kt의 MeterView와 DeltaBarView는 벤치마크 결과·비교 화면 전용 막대 뷰입니다. MeterView는 이번 run 값을 가로 막대로, baseline 값을 같은 스케일의 눈금으로 그려 저하 여부를 숫자 없이 보여 줍니다(저하면 statusFail, 아니면 primaryOnDark). DeltaBarView는 0 기준선 좌우로 변화율 막대를 그리며, 화면의 모든 행이 최대 변화율 하나를 공유 스케일로 씁니다. 두 뷰 모두 Look 토큰 색만 사용하고 onDraw에서 직접 그립니다. 막대의 분율 계산은 ResultPresenter.keyMetrics와 CompareRow.deltaPct가 담당하므로 뷰에는 수치 로직이 없습니다.
