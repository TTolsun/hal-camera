ShutterButton과 ExpandingZoomControl은 Live 하단의 촬영 조작입니다.

ShutterButton은 72dp 기준 크기에 맞춰 셔터를 직접 그립니다. 사진 모드는 흰 원, 동영상 모드는 흰 테두리 안의 빨간 원, 녹화 중에는 흰 테두리 안의 모서리가 둥근 빨간 사각형이며, 빨간색은 Look.statusFail입니다. 크기와 사용 가능 여부, 촬영 동작은 호출하는 화면이 정하고, 버튼은 상태에 맞춰 접근성 설명과 녹화 중 상태 설명만 바꿉니다.

ExpandingZoomControl은 평소 현재 배율 하나만 보여 주고, 지원 배율이 두 개 이상일 때 누르면 모든 배율로 펼칩니다. 펼침은 260ms, 접힘은 220ms이며 시스템 애니메이션이 꺼져 있으면 즉시 바뀝니다. 마지막 조작 후 3초가 지나면 접고, API 29 이상에서는 접근성 권장 시간을 따릅니다. 가로 드래그 중에는 접기 타이머를 멈추고, TalkBack이 켜져 있으면 자동으로 접지 않는 대신 배율을 고르는 즉시 접습니다. 화면 조작 순서는 ui-zoom 관점의 상태도가 따로 그립니다.

두 파일은 ui-widgets의 요소 스캔 입력이 6만 자 한도에 가까워져 이 하위 요소로 내렸습니다.
