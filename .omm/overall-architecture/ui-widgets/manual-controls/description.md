ManualControlPanel은 상단 도구 행의 M 아래에 열리는 비모달 Manual 패널입니다. ISO·Shutter·Focus·WB 중 하나만 펼쳐서 조절합니다. 입력 숫자가 요청값을 담당하고 실제 capture result는 하단 줄에 표시합니다. 선택한 ISO 또는 노출 시간은 LiveReadings에서 중복 표시하지 않습니다. 헤더·탭의 위쪽 위치는 유지하고, 자동값 패널은 232dp, 수동 조절 패널은 280dp로 높이를 줄입니다. 편집 영역만 스크롤합니다. CameraX에서는 진입 버튼을 미지원 상태로 비활성화하며 설명 전용 패널을 열지 않습니다.

슬라이더는 드래그 중 뷰를 다시 만들지 않고 현재 요청을 전달합니다. 숫자 직접 입력은 범위를 검사하고 잘못된 값이면 입력창에 오류를 표시합니다. 접기와 뒤로 가기는 값을 유지하며 전체 자동은 노출·초점·WB를 초기화합니다. 카메라·엔진을 바꾸면 입력창을 닫고 자동으로 초기화합니다.

선택한 탭과 Auto·Manual은 흰 캡슐로 표시하고 편집값과 슬라이더를 강조합니다. 닫기 아이콘은 설정을 유지하며 패널만 접습니다. WB 선택은 PIP와 같은 LiveChoiceSheet를 사용합니다. 자동값은 편집 영역에 표시하고 수동 적용값은 하단에 유지하며 반복 안내 문장은 생략합니다.

주요 글씨는 12sp, 보조 값은 10sp이며 배경은 EV와 같은 알파 120의 cameraControlGlass입니다. ISO·Shutter·Focus·WB 탭은 같은 폭이며 터치 높이는 48dp를 유지합니다. 패널은 펼친 동안만 표시합니다. 닫힌 후에는 별도 요약 패널 대신 LiveReadings의 설정 행에 수동 요청값을 표시합니다.

M·EV·Flash를 열면 도구 행은 유지되고 선택한 버튼 아래의 연결 표시가 패널을 가리킵니다. 한 번에 하나만 펼치며 같은 버튼을 다시 누르거나 상단 화살표를 접으면 패널을 닫습니다. Manual 값 조정 중에는 패널을 유지합니다.

Flash 모드 패널은 왼쪽에 붙이며 모드별 56dp 칸과 양끝 4dp 여백만큼 너비를 사용합니다. 선택 버튼의 원과 터치 높이는 기존 도구 버튼 크기를 유지합니다.
