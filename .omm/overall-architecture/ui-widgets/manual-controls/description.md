ManualControlPanel은 셔터 위에 떠 있는 비모달 Manual 패널입니다. ISO·Shutter·Focus·WB 중 하나만 펼쳐서 조절합니다. 입력 숫자가 요청값을 담당하고 실제 capture result는 하단 줄에 표시합니다. 선택한 ISO 또는 노출 시간은 LiveReadings에서 중복 표시하지 않습니다. 펼친 패널의 높이와 헤더·탭 위치를 유지하고 편집 영역만 스크롤합니다. CameraX에서는 진입 버튼을 미지원 상태로 비활성화하며 설명 전용 패널을 열지 않습니다.
