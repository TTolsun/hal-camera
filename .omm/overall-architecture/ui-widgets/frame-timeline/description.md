TimelineView.kt는 Live 진단 패널의 Frame callback timeline 전용 뷰입니다. 최근 프레임의 START·PARTIAL·BUFFER 도착 시각을 위쪽 점선으로, 세션 평균(p50)을 아래쪽 점선으로 그려, 지연이 어느 구간에서 생겼는지 숫자를 읽지 않고도 보이게 합니다. 두 행은 네 값 중 최대값에 1.15를 곱한 공통 축을 쓰므로 서로 견줄 수 있습니다. 최근 PARTIAL이 세션 평균의 1.3배를 넘고 차이가 10밀리초보다 크면 위쪽 행을 late 색으로 그립니다. 값 라벨은 각 점 아래에 적되, 두 라벨의 그리기 영역이 겹칠 만큼 점이 가까우면 하나로 합쳐 두 점 사이에 적습니다. PARTIAL과 BUFFER는 평시에도 몇 밀리초 안에 함께 도착하므로, 겹침을 그대로 두면 두 값이 이어진 한 덩어리 숫자로 읽히기 때문입니다. 뷰는 Look 토큰 색만 쓰고 onDraw에서 직접 그리며, 값 계산은 MainActivity가 넘긴 이벤트에서 이미 끝나 있으므로 수치 로직을 갖지 않습니다.
