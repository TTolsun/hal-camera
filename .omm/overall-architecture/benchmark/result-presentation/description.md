ResultPresenter와 ComparePresenter는 완료된 run과 RunComparison을 화면 모델로 바꾸는 순수 Kotlin 레이어입니다. ResultPresenter.headline은 판정 한 줄(`N metrics degraded`·`No degradation`·`First run` 등)과 색 톤을 결정하고, metricBars는 측정한 모든 항목을 카테고리별로 묶어 공유 스케일의 막대 분율과 기준 눈금 위치로 계산합니다. 기준 run에만 있는 지표도 눈금만 있는 행으로 남기고, 변화량에는 변화율을 덧붙이며, 판정하지 못한 이유를 note로 넘깁니다. 색(tone)은 baseline과 비교할 때만 판정을 따르고, 이전 run이나 직접 고른 run과 비교할 때는 NEUTRAL입니다. referenceFacts는 기준 run의 시각·빌드·발열과 빌드 비교를 실행 정보 쌍으로 만듭니다. Preview 묶음은 H.1을 뒤집은 `Frame rate`로 시작합니다. 막대가 쓰는 값은 표본의 중앙값이며, 이는 BenchmarkEvaluator가 `value = p50`으로 채운 대표값입니다. statHeader는 옛 표가 중앙값 옆에 두던 두 번째 통계의 이름이므로 막대 라벨로 쓰지 않습니다. runFacts는 실행 정보를 라벨·값 쌍으로 만들고 validity flag를 코드 대신 뜻으로 적습니다. 기존 표 모델(sections·eligibilityLine·comparisonLine)은 복사 텍스트와 History 화면이 그대로 씁니다.

ComparePresenter는 두 run을 나란히 놓은 비교 모델을 만듭니다. 화면은 더 이상 이 모델을 그리지 않고 ResultPresenter.metricBars의 막대와 눈금을 씁니다. 판정 단어는 `degraded`·`Improved`이며 `Regressed`는 쓰지 않습니다. 두 presenter 모두 Android 의존성이 없어 JVM 테스트(ResultPresenterTest·ComparePresenterTest)로 검증합니다.
