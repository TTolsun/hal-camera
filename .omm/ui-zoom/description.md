`ExpandingZoomControl`은 평소에 현재 배율 하나만 보여 주고, 지원 배율이 두 개 이상일 때 누르면 모든 배율로 펼쳐집니다. 펼침은 260ms, 접힘은 220ms 동안 진행하며, 시스템 애니메이션이 꺼져 있으면 즉시 바뀝니다.

펼친 상태에서 배율을 고르거나 포커스를 옮기면 접기 타이머를 다시 시작합니다. 타이머는 3초이며, API 29 이상에서는 `getRecommendedTimeoutMillis`가 돌려준 접근성 권장 시간을 씁니다. 가로 드래그 중에는 타이머를 멈추고, TalkBack이 켜져 있으면 자동으로 접지 않는 대신 배율을 고르는 즉시 접습니다. 컨트롤이 비활성화되거나 진단 패널이 열리면 애니메이션 없이 접습니다.
