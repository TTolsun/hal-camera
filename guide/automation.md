<h1 lang="en">Run. Repeat. Collect.</h1>

**직접 명령을 실행할지, 에이전트에게 맡길지 고르세요.** 두 방법 모두 PC의 ADB로 기기에 연결하고 같은 앱 명령을 사용합니다.

| 실행 방법 | 시작할 문서 | 필요한 것 |
| --- | --- | --- |
| 터미널이나 스크립트에서 실행합니다. | [CLI 명령](cli.md) | ADB가 있는 PC와 연결한 기기가 필요합니다. |
| 코딩 에이전트에게 촬영·측정을 요청합니다. | [에이전트 사용법](coding-agents.md) | PC에서 ADB를 실행할 수 있는 에이전트와 halcam-cli 스킬이 필요합니다. |

## 처음 연결하세요

1. 기기에 APK를 설치하고 USB 디버깅 연결을 승인합니다.
2. PC에서 `adb devices -l`로 대상 기기를 확인합니다.
3. [CLI 준비 절차](cli.md) 또는 [에이전트 준비 절차](coding-agents.md)에 따라 실행 도구를 준비합니다.

ADB CLI는 기본으로 허용됩니다. 직접 꺼 둔 경우에는 앱의 `Lab → ADB CLI`에서 다시 켜세요. 무선 연결과 여러 기기의 구분은 CLI 문서에서 안내합니다.

## 완료와 결과를 확인하세요

**요청 접수는 촬영이나 파일 저장의 완료가 아닙니다.** 요청 ID로 최종 상태를 확인하고, PC로 받은 파일의 크기와 SHA-256을 확인하세요. 연결이 끊겼다면 같은 촬영을 다시 제출하기 전에 기존 요청의 상태를 조회하세요.

벤치마크 실행이 성공해도 비교나 점수에 사용할 수 없는 결과가 있을 수 있습니다. 결과의 validity와 실행 조건을 함께 확인하세요.
