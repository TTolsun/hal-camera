<h1 lang="en">Hand the camera to a coding agent.</h1>

**아래 요청 예시를 복사하고 저장 위치를 바꾸세요.** HAL CAM APK, 스킬 파일, PC에서 ADB를 실행할 수 있는 에이전트가 필요합니다. 앱 소스나 빌드 도구는 필요하지 않습니다.

## 작업을 준비하세요

1. [CLI 연결 절차](cli.md#처음-실행하세요)에 따라 기기와 APK를 준비합니다.
2. [Download](download.md)에서 설치한 APK와 **같은 릴리스**의 `halcam-cli-*-SKILL.md`를 받아 작업 폴더의 `halcam-cli/SKILL.md`로 저장합니다. APK와 함께 전달받은 호환 스킬이 있으면 그 파일을 사용합니다. 스킬은 이 파일 하나로 배포할 수 있습니다.
3. 에이전트에게 아래 요청을 전달합니다. 웹 채팅에 파일을 첨부하는 것만으로 기기가 연결되지는 않습니다.

앱을 업데이트하면 에이전트가 APK에 포함된 실행 스크립트를 다시 준비합니다. APK와 스킬은 같은 릴리스로 함께 갱신하세요.

## 다음과 같이 요청하세요

휴대폰이 한 대 연결되어 있다면 아래 예시를 그대로 요청할 수 있습니다. 여러 대가 연결되어 있다면 사용할 기기를 지정합니다. 스킬과 결과 폴더 경로는 자신의 PC에 맞게 지정합니다.

```text
halcam-cli/SKILL.md를 읽고 연결된 휴대폰의 카메라 0으로 사진을 한 번 촬영해 줘.
결과를 ./photos에 받고 요청 ID, 완료 상태, 파일 검증 결과를 알려 줘.
```

```text
halcam-cli/SKILL.md를 읽고 연결된 휴대폰의 카메라 0으로 무음 영상 10초를 촬영해 줘.
저장 완료까지 확인하고 MP4를 ./videos에 받아 검증해 줘.
```

측정이 목적이면 작업을 “표준 벤치마크 한 번”으로 바꾸고 원본 JSON·validity 확인을 요청하세요. 명령별 옵션은 [CLI 가이드](cli.md)에서 확인합니다.

## 결과를 확인하세요

1. 대상 기기와 앱 버전이 맞는지 확인합니다.
2. 요청 ID와 최종 상태, 받은 파일의 경로·크기·SHA-256 검증 결과를 확인합니다.
3. 벤치마크라면 JSON의 validity에서 측정·비교 가능 여부를 확인합니다. 보고서 저장 성공과는 별개입니다.

연결이 끊기면 같은 작업을 다시 요청하기 전에 기존 요청 ID로 상태를 조회하세요.

**다음 단계:** 결과를 공유할 때에는 [Validation](evidence.md)의 검증 범위를 확인하세요.
