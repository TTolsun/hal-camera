## 설치하고 첫 촬영을 시작하세요

GitHub 릴리스의 Assets에서 `HAL-Camera-*.apk`를 받아 기기에서 엽니다. 설치 허용과 카메라 권한 설정은 [Quickstart](getting-started.md#apk를-설치하세요)에 안내되어 있습니다.

업데이트에서 서명 오류가 나면 기존 설치와 같은 서명의 APK를 받으세요. 앱을 삭제하면 내부 실행 기록이 사라집니다.

<details markdown="1">
<summary>릴리스에 함께 있는 파일은 무엇인가요?</summary>

| 파일 | 필요한 경우 |
| --- | --- |
| `halcam-cli-*-SKILL.md` | 코딩 에이전트로 앱을 조작할 때 APK와 같은 릴리스의 파일을 받습니다. |
| `SHA256SUMS.txt` | 내려받은 파일의 SHA-256 해시를 확인할 때 사용합니다. |

`Source code (zip)`과 `Source code (tar.gz)`는 소스 코드입니다. 앱 설치에는 `.apk` 파일만 필요합니다.

</details>
